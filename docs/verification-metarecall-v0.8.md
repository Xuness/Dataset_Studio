# 0.8 Danbooru 元数据排名：实现与验证

2026-09-09。本次实现按项目范围固定元数据、计算 MetaRecall v1，并发布可浏览、解释和转换为工作集的排名成果。原始公式文档保持原文，实施口径见 `设计文档/Danbooru元数据筛选公式/实施设计 v0.8.md`。

## 已接入的功能

- “计算工具 → Danbooru 元数据排名”：参数配置、结果榜单、统计诊断和单图评分依据；旧清单和标量计算在“基础工具”中继续可用。
- 数据湖、查询结果、工作集和当前选择均可作为输入。成员、查询分支和来源版本在提交后固定；最新代表记录仍须命中本次条件，并与当前图片内容相符。
- G/C/A/V/T、主分 S、补救分 R、分级内排名、精确名额和独立随机审计。画师先验已实现，默认关闭。成品最短边是可选用途条件，默认不读取尺寸回退字段。
- 资格、缺失提示和入选通道分别保存；“未知”和“未入选”不等于视觉质量差。
- 有界榜单、跨页保存工作集、查询依据及成果引用保护；取消、重试、检查点恢复及原子发布。
- 项目数据库 v8，清单版本仍为 1；旧项目升级前制作一致性备份。

## 自动检查

`pnpm contracts` 已生成契约。`pnpm check` 覆盖 TypeScript、ESLint、模块依赖边界、契约漂移、Rust fmt/clippy、Rust 单元测试及客户端测试。`pnpm test:integration` 包含八组独立引擎集成脚本。另执行 `pnpm build:web` 和实际界面检查。

算法 oracle 独立核对中位秩、全标签匹配、日期边界、日历月份截断、扩展邻域、K 收缩、画师自排除与关联组限权、名额和种子复现。时间窗口边界在月末可能回退，测试覆盖滑动窗口两端的反向调整。跨来源去重另覆盖同日日期级/精确观察、跨日先后及未知精度。

`tooling/integration-ranking.mjs` 的夹具包含 1,025 个真实 PNG 图片对象及丰富关联观察。12 项验证覆盖代表记录、查询条件、历史图片版本、严格尺寸、四种范围、逐行复现、分页游标隔离、工作集幂等与引用保护、取消重试，以及带部分分级检查点的强制中断恢复。隐藏来源入口后恢复所得每行结果仍与首次执行一致，成果没有重复发布。夹具两个来源索引的 SHA-256 保持一致，排名和恢复的图片读取计数为零。

`tooling/smoke-ranking-ui.mjs` 使用实际 React 页面、独立引擎和独立 Edge 浏览器上下文。验证提交、48 行分页、分级切换、真实预览、评分依据、诊断、跨未加载页面保存 75 个成员、模块切换及页面重连恢复。截图检查覆盖 2560×1440、1540×1000 和 1000×760，并检查属性面板显隐、键盘调整宽度、点击行显示依据和配置分组折叠。测试端口适配只作用于该浏览器上下文；应用自身来源限制保持原有配置。

界面按用户提供的 `参考风格/Adobe设计参考/Photoshop主页面图.png` 调整：深灰工作区、紧凑选项栏、方正的停靠面板、克制的颜色标记。按后续反馈放大一档，常用文字为 12–13 px、输入框 28 px、榜单行高 33 px。榜单滚动时表头和翻页栏保持可见，评分依据使用右侧属性区，任务进度显示在页面内。
