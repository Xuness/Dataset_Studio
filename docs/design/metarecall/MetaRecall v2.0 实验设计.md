# Danbooru 图片筛选：MetaRecall v2.0 实验设计

日期：2026-09-13（北京时间）

状态：总体方案仍为实验设计；首版元数据阶段已接入。视觉 Bridge 与视觉召回收益验证尚未开展，落地范围见第 17 节。

适用项目：Dataset Studio。本文版本不等同于应用版本。

本文将本轮讨论整理为可以开展试点的方案：按 Rating 调整公式，以类型适配保护目标图片，通过 Bridge Image 建立跨年代尺度，在时间边界采用连续羽化，并保留直算总榜、桥接总榜及其可调融合。最终以固定成本下的好图损失和多个前段截取位置的质量验证效果。

关联文档：[MetaRecall v1 原始设计](GPT-6%20Astra%20Pro%20v1.0.md)、[现有实施设计 v0.8](实施设计%20v0.8.md)。两份旧文档继续作为原方案与现有实现的记录；本文不将 v2 能力描述为已经接入。

## 1. 已确定的目标与边界

### 1.1 根本目标

元数据筛选用于降低下一阶段精排成本。由于尾部会被截断，排名必须尽量将目标好图送到预算覆盖的前段，减少漏失，同时使前段具备进一步分层处理的价值。

“召回器”不构成接受好图长期留在尾部的理由。相同候选池和相同保留数量下，让更多目标好图进入前段，就是召回改善。前段不同位置之间的精细程度，则要通过多个预算截取点另行验证。

确定以下设计方向：

1. G、S、Q、E 分别建立统计与排名，允许不同权重、收缩规则和公式结构。
2. 元数据、用途类型、视觉比较提供不同证据，不要求一个公式完成全部任务。
3. 保留直接计算总榜的方式，并新增跨年代桥接分支，允许调整两榜融合权重。
4. 年份用于组织与解释，实际时间修正连续变化，不以跨年作为生硬分界。
5. Bridge Image 覆盖不同排名区间，也覆盖深尾部、低曝光和信息缺失情况。
6. 允许调整指定年代的候选占比，将这种偏好与质量校准分别记录。
7. 不确定、预算未入选、用途不适配和已确认质量问题分别表达。
8. 验证必须覆盖未入选图片，不能只在筛选后的候选中证明公式有效。

### 1.2 漫画与分镜的最终约定

只对符合本轮“典型纯漫画”定义的部分降低主任务优先级。完成度高、具有充分视觉表现的 2–4 幅／页分镜式插画应保留，即使画面之间具有连续叙事关系。

多视角、局部特写、画面嵌入、精良的多镜头构图，不因多画面、分页数量或叙事顺序而自动降分。两格可能是典型漫画，四格也可能是精良插画；数量不作为硬阈值。

这项约定优先于讨论中较早的“连续叙事作品统一另排”解释。站点 `comic` 分类与本轮用途分类不是一一对应关系。

### 1.3 本文不承诺的结果

本文提出可验证的改进机制，不承诺零漏图，不将元数据分或桥接相对分解释为天然的审美概率。Bridge 带来的视觉证据只覆盖实际评估的图片；其他图片的修正仍属于模型估计。

不把“近年占比提高”“分数更分散”“排名不再并列”“计算成功”单独视为质量收益。

## 2. 评价对象与成功标准

### 2.1 质量、用途和确定性分别标注

建议独立保存：

| 维度 | 试点标签 |
| --- | --- |
| 视觉质量 | 优秀、良好、一般、较差、无法判断 |
| 主任务适配 | 适配、降低优先级的典型漫画、其他特殊类型、类型不确定 |
| 分镜保护 | 精良分镜、多视角／特写构图、非此类型、无法判断 |
| 判断依据 | 人工、模型、联合复核及各自版本 |
| 判断确定性 | 足以判断、需要更多观察、图像材料不足 |

质量等级与用途类别不相互替代。高质量漫画仍可在其独立分组内排名；不能为了改善主榜指标，把它标成低质量。模型或 Tag 的类型预测也不能直接当作验收真值。

### 2.2 主要指标

在固定候选池、固定下一阶段预算下，主指标为：

$$
\operatorname{Recall@B}
=\frac{\text{进入下一阶段的目标好图数}}
{\text{候选池中全部目标好图数}},
\qquad
\operatorname{Loss@B}=1-\operatorname{Recall@B}.
$$

其中“目标好图”的质量门槛与用途定义必须在实验配置中固定。另行报告全部视觉好图、优秀图、典型漫画及类型不确定图片的覆盖情况，不能通过改变分母隐藏损失。

尾端好图占比是辅助指标。举例：80 万张尾池中只有 0.5% 好图，仍意味着漏掉 4,000 张；需要同时报告漏图数量和占全部好图的比例。

至少报告：

- 目标好图召回率、优秀图召回率及其区间估计。
- 前 1%、5%、10%、20% 和目标截断比例下的候选质量；比例是观察位置，不是固定产品配额。
- 被截断的好图数量估计、尾部好图密度。
- 各 Rating、年代、曝光状态、主要类型的上述指标。
- 精良分镜被错误降分、被推过截断线的比例，以及典型漫画识别效果。
- Bridge 独有补救和直榜独有补救分别找回多少好图，同时替换掉多少边缘好图。
- 新方案相对基线的成员变化、年代构成变化和实际资源成本。

### 2.3 同时比较质量与成本

基础实验可暂按每张进入精排的图片具有相同成本，以保留数量 N 表示预算；正式应用还需要统计多图比较、局部放大、重复判断、API 消耗、GPU 时间等实际成本。

Bridge 校准成本单列，分别报告首次使用总成本和重复筛选时的摊销成本。不能只报告“精排数量减少”，却忽略新增桥接视觉比较的成本。

## 3. 现有基础与实验前的口径核查

当前实现已经具备固定输入、按 Rating 计算、主分／补救分、中间特征、稳定并列处理和成果物化等基础。

2026-09-13 的本地只读调查提示以下问题，应在实验前处理或隔离：

| 观察 | 实验含义 |
| --- | --- |
| 当前成果使用仅排名模式，画师项关闭 | 原设计的主／补救／审计配额没有实际生成保留集合，不能把它作为已验证的完整召回策略 |
| 当前查询 Rating 与冻结评分代表记录可能不一致 | 列表末尾可能包含其他原分级的高分图，应先排除分段展示造成的假低分现象 |
| 新图样本中存在观察时间未知 | 年代羽化不能替代真实帖龄，缺失状态需单独建模与抽样 |
| 极前段样本没有获得时间补救加分 | 调整时间系数的效果必须实测，不能默认头部问题来自时间补救过强 |
| 早期帖子存在净分与赞／负票分项不一致 | 先查历史字段口径，不凭不一致直接判低质量或自动反推修补 |
| v1 排名输入未完整保存新类型规则需要的所有 Tag | 新特征需按原观察身份补取并冻结，不能把当前标签无声拼接到旧热度快照 |

上述是数据与实现层面的证据，不是视觉质量验证。本地调查材料位于 `.local/reports/metarecall-design-review-20260913/`；它属于机器上的调查记录，不作为仓库必须附带的数据输入。

## 4. 总体流程

~~~mermaid
flowchart TD
    A["固定候选、代表记录与用途范围"] --> X["共享元数据与类型特征"]
    X --> D["按 Rating 计算直榜 D"]
    X --> T["连续时间邻域与初始相对位置"]
    T --> S["分层抽取 Bridge Image"]
    S --> V["跨年代、跨分位视觉比较"]
    V --> C["共同尺度、时间曲线与个体修正"]
    T --> C
    C --> B["桥接总榜 B"]
    D --> F["统一尺度后融合"]
    B --> F
    D --> R["单榜补救入口"]
    B --> R
    V --> R
    F --> P["用途调整、年代偏好与预算选择"]
    R --> P
    P --> N["分层进入后续精排"]
    X --> E["独立分层验收样本"]
    E --> Z["同预算召回与损失评估"]
    N --> Z
~~~

逻辑阶段如下：

| 阶段 | 主要职责 | 截断原则 |
| --- | --- | --- |
| 基础整理 | 固定身份、字段、用途和 Rating；生成可复用特征 | 文件无效与用途分流单独记录 |
| 广泛召回 | 由直榜、同条件突出表现、桥接等提供机会 | 保持较宽范围，避免单一低分过早淘汰 |
| 候选细排 | 用经验证的分 Rating 组合和桥接信息区分前段 | 保留原分数、修正值、缺失与不确定性 |
| 预算选择 | 执行补救名额、年代偏好和成本限制 | 形成唯一、可复现的下一阶段成员集 |
| 后续精排 | 以图像为依据进一步判断与排序 | 接收必要输入，不默认暴露元数据分作为审美先验 |

多阶段不等于多次激进截断。若两个阶段分别保留进入该阶段好图的 95%，最终只剩初始好图的 90.25%。实验应逐级统计累计漏失，并保留来自第一阶段尾部的补救和审计入口。

## 5. 固定数据与共享特征

### 5.1 身份和代表记录

2026-09-13 接入补充：用户后续明确要求“热度优先较高记录或不同重复帖求和，分级默认取最新元数据”。当前默认规则与旧完整代表规则的兼容方式见 [0020：重复帖热度、最新分级与评分浏览口径](../../decisions/0020-duplicate-post-ranking-evidence.md)。下述单一代表约束保留为旧方案定义；新方案分别冻结元数据依据和热度依据，并公开展示来源。

- 图片以实际内容身份去重；帖子、图片文件与历史观察分别记录。
- 一张图片用于本次评分的 Rating、热度、标签和时间来自同一套明确的代表记录规则。
- 重新补取字段时以冻结观察身份连接，不从不断变化的当前记录中择优拼接。
- 元数据多记录冲突必须可追溯。原评分分级和当前查询分级不一致时，不能把不同分级名次简单首尾相接后冒充单一质量总榜。
- 改变代表记录、来源快照或统计总体，形成新版本；不覆盖原成果。

### 5.2 共享特征

| 特征组 | 内容 | 约束 |
| --- | --- | --- |
| 互动 | 收藏、赞票、负票、净分诊断、对数热度 | 不把高度关联的收藏、赞票、净分当三份独立证据 |
| 时间 | 上传日期、真实观察日期、帖龄区间、精度 | 不以今天、入库时间或 updated_at 替代 observed_at |
| 支持量 | 正面互动支持、比较群体有效数量、缺失状态 | 低支持与低质量分开 |
| 创作者 | 真实画师先验、其他作品支持量 | 排除当前图片，关联变体限权；允许 A=0 |
| 类型 | 原始 token、规范化类型、冲突、保护标记 | 原始证据保留，分类版本固定 |
| 技术问题 | 压缩／扫描损伤等明确证据 | 同类不重复累加，缺少标签不代表确认无缺陷 |
| 可选视觉 | 实际生成的视觉特征、版面判断、比较结果 | 记录生成覆盖与成本；不存在的视觉特征不能当作已计算 |
| 可靠性 | 各字段质量、来源口径、回退原因 | 不用一个笼统“缺失扣分”替代具体处理 |

共同热度可继续以 `(1+fav_count)(1+up_score)` 的精确整数键排序；它与 v1 的对数合并顺序一致。收藏或赞票只有一项有效时沿用单项规则，两项均未知时保留未知状态，不补成零互动。净分继续作为一致性诊断，不自行推断历史分项票数。

## 6. 分 Rating 公式与两类评分职责

### 6.1 共用骨架，允许独立参数与结构

| 分级 | 首轮实验侧重点 |
| --- | --- |
| G | 类型适配、低曝光与不确定性；检验降低累计热度支配程度的收益 |
| S | 在互动排序基础上检验类型、帖龄和支持量的条件组合 |
| Q | 保留当前有效部分作为基线，谨慎验证结构变化与新图补救 |
| E | 保留当前有效部分作为基线，验证桥接、时间与独有补救收益 |

这是实验优先级，不是“某分级天生采用某个权重”的定论。四个分级分别保存参数；证据不足时向共享参数收缩，不切成大量互不借力的小群体。

### 6.2 直榜候选结构

保留 v1 作为基线，另设允许有限双向时间修正的候选族。以下是待验证的结构，不是已确定的新公式：

$$
D_i^{raw}
=G_i+\alpha_r(m_i)(C_i-G_i)_+
-\gamma_r(m_i)(G_i-C_i)_+
-\nu_rV_i-T_i.
$$

其中：

- G、C、V、T 沿用 v1 特征含义，r 为 Rating。
- m 表示帖龄、互动支持与时间可靠性等状态，不是已校准的审美置信概率。
- α 控制同条件突出表现的帮助；γ 控制绝对热度与同条件表现不一致时的有限修正。
- γ=0、α=0.30、ν=0.08 且特征相同时，可保留 v1 主分结构。
- γ 大于 0 可能误伤累计热度高的优秀作品，必须单独消融；时间未知时不能据此构造负面证据。
- 也允许采用更一般的共享函数加 Rating 修正，但首轮控制自由度，避免同时调太多参数。

计算与存储保留未舍入值。是否截到 0–100、在哪一层截断作为版本化规则；不能因显示范围制造大量并列，再声称细排更精确。

### 6.3 召回与细排

召回阶段允许由不同证据提供候选：直榜强项、同条件突出、桥接强项、实际评估的优秀 Bridge、未知数据探索。

细排阶段对已经获得机会的候选综合排序。不能只将原分数重新映射成百分位、扩大数值范围或增加小数位，就认为获得了新的区分能力。

创作者先验可作为受限的召回或个体修正特征。关闭时 A=0 表示不提供帮助；不能把画师模块视为实验必须完成的前置阻塞。

## 7. 类型适配规则与分镜保护

### 7.1 使用项目用途分类

| 项目类型 | 示例特征 | 主任务处理 |
| --- | --- | --- |
| 典型纯漫画 | 对白／阅读推进占主要作用的漫画页、连载内容；需结合整体判断 | 降低主榜优先级，可进入独立漫画分组 |
| 精良分镜式插画 | 2–4 幅／页高完成度画面，具备充分视觉表现；允许连续叙事 | 不承担漫画类型惩罚 |
| 多视角／特写构图 | 多姿态、多视角、局部插入、cut-in 等 | 不因构图形式降分 |
| 混合或不确定 | Tag 与画面冲突，漫画阅读和插画展示并存 | 保留不确定状态，暂缓明显降分 |

“纯漫画”属于面向本轮目标的用途判断。黑白、气泡、文字、长宽比、格数和连续叙事都不是单独充分条件。

站点 [comic](https://safebooru.donmai.us/wiki_pages/comic) 分类覆盖连续叙事作品；[multiple_views](https://safebooru.donmai.us/wiki_pages/multiple_views?z=1) 和 [cut-in](https://safebooru.donmai.us/wiki_pages/cut-in) 描述不同的构图形式。站点 token 可作为线索，不能替代项目用途判断。

### 7.2 规则组织方式

类型规则记录“命中证据—适用范围—保护／冲突条件—影响上限—版本”，不建立未经验证的通用负面 Tag 大名单。

1. 使用完整 token 和固定版本的别名／蕴含关系，不用字符串包含关系匹配。
2. 同一类型族只计一次影响。例如 `4koma` 与它蕴含的 `comic` 不能重复扣分。
3. `comic`、`1koma`、`2koma`、`4koma`、`full_page_comic` 等仅作为漫画候选线索，不能单独触发大幅惩罚。
4. `multiple_views`、`cut-in` 等提供构图保护线索；混合命中首先视为需核对的证据，不设“一条白名单覆盖所有判断”。
5. 分镜保护只豁免误用的漫画类型惩罚；真实技术损伤仍独立处理。
6. 未知类型默认不承担明显惩罚；会使图片跨过截断线的类型重罚需要更充分的证据。
7. 纯元数据版本采取保守处理；要区分同样带 comic 标签的精良分镜与典型漫画，需引入图像判断并验证误伤率。
8. 跨多个文件的分镜作品保留逐图身份，可利用可靠的作品组上下文辅助类型判断；不能因一页属于某个组就复制其他页的质量结论。parent 关系本身也不能证明是漫画或确切重复。

站点已有漫画标签误用于普通对白图、黑白图等讨论，说明不能把命中 token 当作无误差真值：[1koma 标签清理讨论](https://safebooru.donmai.us/forum_topics/23117)。

### 7.3 其他特殊类型候选

| 类型 | 首轮建议 |
| --- | --- |
| 文字主导图、界面／游戏截图、精灵图集 | 建立用途类别，抽样确定是否与本轮目标不匹配 |
| 设定图、参考图、表情／服装展示 | 可能具有较高训练价值，先独立观察，不自动降分 |
| 扫描、线稿、黑白、简单背景、草图式表达 | 不仅凭类型判低质量；若需改变用途偏好，作为单独配置 |
| 压缩损伤、扫描损伤等技术问题 | 按证据与影响上限处理，避免相关标签重复扣分 |
| 同系列变体与近重复 | 单独评价新增训练信息，不直接改写单图视觉质量 |

这张表是实验候选清单，不是已经启用的处罚清单。典型漫画以外的类型仍需通过样本明确处理方式。

用途惩罚 P_type 单独保存，并在最终筛选优先级中计入一次。不能在直榜、桥接榜各扣一次，融合后再扣一次。

## 8. 时间羽化：跨年份边界连续过渡

### 8.1 区分两条时间轴

- 上传时间 t：用于年代组织和连续校准，不直接等同于作品创作年代。
- 采集时帖龄 a=observed_at-created_at：用于解释互动累积程度。

年份羽化只解决年代边界。真实观察时间缺失、日期精度不足和近期票数尚未成熟，仍需单独处理。

### 8.2 首轮采用跨边界 smoothstep 权重

设 b 为相邻两年的边界，h 为羽化半宽，t 使用同一 UTC 时间单位。h 大于 0 时：

$$
u=\operatorname{clip}_{[0,1]}\left(\frac{t-(b-h)}{2h}\right),
\quad
s(u)=3u^2-2u^3,
$$

$$
w_{\mathrm{new}}=s(u),
\qquad
w_{\mathrm{old}}=1-s(u).
$$

在边界前 h 之外完全采用旧时期权重，在边界后 h 之外完全采用新时期权重；中间连续过渡，两端的一阶导数为零。

以 h=90 天为机制示例：

| 距跨年边界 | 旧时期权重 | 新时期权重 |
| --- | ---: | ---: |
| -90 天 | 100% | 0% |
| -45 天 | 84.375% | 15.625% |
| 0 天 | 50% | 50% |
| +45 天 | 15.625% | 84.375% |
| +90 天 | 0% | 100% |

h 是半宽，因此 90 天表示整个过渡带约 180 天。它是试点起点，不是已验证最优值。

首轮候选 h 为 0、45、90、180 天。h=0 单独实现为硬边界对照，不能代入除法公式。为保持相邻过渡带不重叠，首版限制在上述范围；若以后采用更宽窗口，改用统一归一化的多中心核权重，不能独立相加多个二元羽化函数。

### 8.3 羽化应用于统计和校准两处

**参考样本共享：**边界附近图片按权重参与相邻时期的参考分布，而不是只进入一个年份桶。

**校准结果混合：**同一图片按连续权重混合相邻时期的校准预测，避免在 1 月 1 日突然切换曲线。

共享权重只影响统计贡献，不复制图片身份，不让一张图占两份 Bridge、候选或年代配额。每张图的时期归属权重之和必须为 1。

对于时期 k，令参考权重 a_jk 同时包含年代羽化与帖龄可比性；同 Rating 有效热度的加权中位秩为：

$$
p_{i,k}=
\frac{\sum_j a_{jk}\mathbf 1[L_j<L_i]
+\frac12\sum_j a_{jk}\mathbf 1[L_j=L_i]}
{\sum_j a_{jk}}.
$$

其中帖龄比较以待评分图片的帖龄状态为条件；正文中的 a_jk 为简写，实现中必须保留这个条件。权重为零或字段无效的记录不参与相应估计。

群体支持量使用：

$$
n_{\mathrm{eff}}=\frac{(\sum_j a_{jk})^2}{\sum_j a_{jk}^2}.
$$

重叠窗口里的记录不能简单按出现次数累加成更大的独立样本量。必要时进一步按关联作品组核查有效支持。

### 8.4 相邻曲线共享信息，但允许年代差异

相邻时期的校准曲线采用共享基础曲线加受约束的时期修正。平滑强度控制“借用邻居信息”的程度，不把各年的分布拉成一样。

可将相邻修正曲线在共同分位网格上的差异平方加入正则项；其强度在开发验证集选择。保留部分真实年代变化，并用数据检查过度平滑与样本稀疏造成的假波动。

连续权重不保证有限样本名次完全连续：秩、票数并列和记录进出仍有离散台阶。验收应检查羽化函数和校准预测是否产生人为日期跳变，不能要求两张不同图片仅因相邻日期就具有相同分数。

### 8.5 边界和缺失处理

- 只有一侧有可靠校准时，向同 Rating 的共有曲线收缩，记录单侧支持；不把缺失侧填零。
- 新时期、稀疏旧时期和校准范围之外的预测记录支持范围与不确定性。
- 时间未知单独抽样；只使用有证据的日期区间，不推断一个看似精确的时间点。
- 日期只有区间精度时，可对区间内权重求平均；积分或近似规则固定版本。
- 主实验只使用同一冻结快照内可用的相邻时期信息。若评估历史在线效果，必须另设按时间截止的实验，禁止使用当时尚不存在的后续作品或观察。

## 9. Bridge Image 的抽样与比较

### 9.1 Bridge 的职责

Bridge 是被实际看过、用于连接不同时期相对质量尺度的图片，同时用于发现原公式的错排。它不是仅凭已有元数据选出的“绝对可靠好图”，也不只从头部产生。

跨年比较必须提供图像依据。如果仍然只比较原来的收藏／赞票分数，无法获得独立的审美校准信息。

### 9.2 抽样覆盖

在每个 Rating 内，按时期和初始排名区间组织抽样。示例区间为前 0–1%、1–10%、10–30%、30–60%、60–90%、90–100%，它们是初始样本设计而非最终保留配额。

额外覆盖：

- 跨年羽化带两侧与边界附近。
- 观察时间未知、低互动支持、字段口径异常。
- 直榜和相对榜明显不一致的图片。
- 典型漫画、精良分镜、多视角图和分类冲突样本。
- 不同画师与视觉类型，限制同一作品组过度占据锚点。

基础随机分层样本与主动补充的反例分别记录。前者保存抽样概率；主动选出的反例用于诊断和训练，不能作为无偏总体样本使用。

### 9.3 连接比较图

- 同一 Rating 的 Bridge 图应形成连接的比较网络，年份和分位不能成为孤岛。
- 同时安排相邻年份、跨较大年代跨度、相同分位和不同分位的比较。
- 保留共同参考图与回路检查，避免只靠一条逐年传递链。
- 每张图与多个不同对手比较，尽量避免只有明显强弱悬殊的对局。
- 比较网络是否连接需要实际检查；给每张图固定若干对手并不自动保证连接。
- 不要求全量两两比较，先保证覆盖和连接，再把新增比较用于不确定区间。

比较网络结构会影响相对质量估计，这是设计交叉连接与补充比较的依据；现有理论结论不能直接当作本项目的效果证明：[Graph Resistance and Learning from Pairwise Comparisons](https://proceedings.mlr.press/v97/hendrickx19a.html)。

### 9.4 判断协议

试点以成对比较为基础；若改为多图组排序，必须保持组间参考连接，并验证缩略图尺寸是否足以判断复杂分镜。不能把一组中必然出现的第一名自动解释为全局好图。

比较输入隐藏年份、帖子 ID、票数、名次、通道和公式分。固定图像预览策略，允许必要的局部放大；放大和额外观察计入成本。

输出至少区分：

- 按固定视觉评价准则，A 更优、B 更优、视觉接近。
- 证据不足无法判断。
- 图像读取或显示有问题。
- 类型判断冲突，需要复核。

“视觉接近”与“没看清／模型失败”不得混成一个并列。重复比较交换位置，检查位置偏好和判断一致性；模型版本、提示词版本、图像哈希、展示参数与输出全部保存。

质量比较和用途分类分别提问、分别输出。训练共同质量尺度时，不把“属于典型漫画所以主任务应降优先级”再次混入质量胜负；用途影响由 P_type 单独处理。人工复核应覆盖不同 Rating、年代和类型，以确认模型判断符合用户标准，而不只验证模型与自身是否一致。

### 9.5 比较模型与共同尺度

首轮可比较支持并列的成对比较模型与保留分数不确定性的排序模型。使用正则化或明确先验处理稀疏连接、单侧全胜等情况，不能强行相信无限大的分数差。

可借鉴 TrueSkill 对相对分数与不确定性的分别表达，但不照搬其游戏参数、动态技能变化或保守下界作为图像筛选规则：[TrueSkill 官方说明](https://www.microsoft.com/en-us/research/project/trueskill-ranking-system/)。

桥接输出是该比较协议下的相对偏好尺度。它不天然等于“成为好图的概率”，也不意味着所有风格偏好都可用完全传递的一维关系解释。明显循环或争议样本保留并复核。

## 10. 从锚点得到桥接总榜，并纠正年内错排

### 10.1 跨年代尺度映射

令 q_i 为 Bridge 比较得到的相对分数，f_rk 为同 Rating、时期 k 的校准函数。对非锚点图片，先计算年代校准部分：

$$
B_i^{time}=\sum_k w_k(t_i)f_{r,k}(p_{i,k}).
$$

函数先分别作用于各时期的相对位置，再混合预测。非线性情况下不能将它随意替换成“先平均分位再套一个函数”。

校准函数采用低复杂度、平滑的形式，样本不足时回退共有曲线。不同年代的曲线允许交叉：某年的尖端作品可能更强，另一年的中高段可能更强。

不要仅给每个年份拟合一个常数加减分，也不要要求所有年份具有相同入选率。

### 10.2 单纯年代映射不能修复年内错排

若一张好图在本年被元数据排到后 80%，只抬高该年尺度仍会让它排在大量本年普通图之后。

因此，年内排名是带噪声的初始预测，不是不可违反的顺序约束。Bridge 显示的年内反转应进入诊断与修正，而不是全部当作噪声抹去。

进一步设：

$$
B_i^{raw}=B_i^{time}+e_r(X_i),
$$

其中 e_r 是利用支持量、时间质量、类型等特征学习的受约束个体修正。允许对已经实际评估的 Bridge 保留其直接判断依据和补救资格。

初版分别评估“仅年代映射”和“加入个体修正”。若没有支持泛化的特征，不宣称少数 Bridge 能自动纠正所有未看过图片的年内错排。

### 10.3 特征覆盖与回退

元数据修正模型只能使用目标范围内实际可获得的字段。若使用视觉向量修正，必须为所评分图片实际生成或取得相同版本特征，覆盖范围和资源消耗单列。

类型不明确或观察时间未知的样本参与相应的回退模式训练；不能把缺失视觉向量补成一个正常零向量。

共有校准模型可为缺少时期支持的图片给出预测，但标明属于共有模型回退，而非该时期已有 Bridge 证据。若连同 Rating 的共有模型都未建立，该 Rating 不启用桥接分支，使用直榜并明确标注不可用。

实验报告必须区分锚点直接证据、模型泛化、共有曲线回退和未覆盖范围。不得只展示有 Bridge 覆盖部分的效果，却宣称全库提高。

## 11. 两榜融合与用途调整

### 11.1 统一尺度

直榜 D_raw 与桥接榜 B_raw 在同 Rating、同一冻结候选总体内分别转换为同向总榜百分位：

$$
d_i=\operatorname{Percentile}_{I_r}(D_i^{raw}),
\quad
b_i=\operatorname{Percentile}_{I_r}(B_i^{raw}),
$$

$$
F_i=100[(1-\lambda_r)d_i+\lambda_rb_i].
$$

百分位采用固定并列规则，分值越大表示越优先。λ=0 为直榜，λ=1 为桥接榜，中间值为融合；各 Rating 可独立设置。

要求：

- 不能直接相加不同单位的原公式分、胜率和桥接相对分。
- 不能在桥接后按每年分别再拉成相同分布，否则会消掉跨年校准。
- 对部分时期缺少证据的情况，先按第 10.3 节生成明确回退预测，再按完整共同总体归一，不能只对有 Bridge 的子集归一后与全库直榜混合。
- 整个 Rating 没有桥接能力时令有效 λ 为 0，不把 b 缺失填为 0。
- 若选择成员改变，不随意重定义已经冻结的参考总体；否则形成另一个实验版本。

后续若有充分视觉标签，可比较共同质量标尺上的融合与百分位融合；不能把首版百分位平均直接解释为校准概率。

### 11.2 用途调整单独记账

最终任务优先级可写为：

$$
J_i=F_i-P_i^{type}+A_i^{era}.
$$

P_type 是一次性用途调整，A_era 是显式年代偏好；两者不改写原始质量证据分。技术惩罚 T 若已在两分支的质量估计中按同一语义处理，融合后不再重复加一遍相同惩罚。

桥接判断中的质量等级与用途标签分别保存，避免把用途扣分当作视觉质量训练目标后又在 J 中重复扣分。

### 11.3 不让融合冲淡补救

直榜低、桥接榜高的图片，在平均后仍可能落到截断线以下。仅取两榜候选并集，再按融合分无条件截断，也不能保证这些图片被保留。

除融合榜外，设置有明确预算的单榜独有补救名额；保护名额实际保留进入下一阶段的机会，融合分用于其后排序。若保护名额与年代硬约束冲突，按照显式规则处理并报告，不能静默取消保护。

两榜具有共同的元数据信息，不把它们当成相互独立的两次质量确认。

## 12. 年代偏好、候选配额与预算分层

### 12.1 两种年代控制

| 控制 | 行为 | 适用目的 |
| --- | --- | --- |
| 软偏好 | 连续调整 A_era | 让指定年代更容易进入候选，但不承诺固定占比 |
| 目标比例／范围 | 选择时约束各年代的候选数量 | 明确控制训练候选的年代构成 |

软偏好也可沿年代边界羽化：

$$
A_i^{era}=\sum_k w_k(t_i)\beta_{r,k}.
$$

β 是用户偏好参数，不是桥接证明的质量提升。关闭偏好时 A_era=0，以便单独验证质量算法。

硬配额的计数必须明确：首版建议按每张图片实际上传年份计一次整数名额；如果以后采用模糊归属配额，应另设模式，用权重贡献计数并另行展示真实整数分布。两者不能混用后声称同一个“年份占比”。

### 12.2 配额与保护的联合选择

预算内考虑以下入口：

- 融合榜主要候选。
- 直榜独有补救。
- 桥接榜独有补救及实际评估的优秀 Bridge。
- 信息不足与深尾部探索。

所有入口去重后只占一份名额。保护名额、年代目标、类型处理与总预算需要共同求解，不能各自独立取满后简单拼接。

建议顺序：

1. 固定总预算、各 Rating 预算、用途规则、年代控制模式与补救规则。
2. 识别候选所属入口及重叠关系，为保护和目标配额检查可行性。
3. 在可行约束下优先分配受保护候选，再按 J 填充剩余名额；软目标允许偏离并报告。
4. 候选不足时按配置回流名额；硬约束不可行时返回明确的不可行原因，不悄悄改变条件。
5. 输出唯一成员集合、实际名额、入选原因和未满足目标。

当前讨论未确定固定的保留比例。v1 的 33.3% 可作为对照预算之一，不自动成为 v2 默认业务限制。

### 12.3 分层进入下一阶段

保留集合可以再分为优先处理、常规处理、需要更多判断的边界候选等层级。前段层级用于分批精筛和分配观察成本，不等于未经视觉验证就自动通过。

低分且信息不足的图片，需要区别于多项有效证据一致指向弱表现的图片。探索名额覆盖整个未入选池，不能只抽截断线附近。

改变年代占比可能改变同预算下的整体质量与损失，这项取舍在独立报告中呈现。质量算法比较时先关闭年代偏好；不能用提高近年占比替代质量验证。

## 13. 试点参数与第一轮实验

### 13.1 参数均为实验起点

以下值用于建立可运行对照，不表示最优权重，也不要求一次穷举所有组合：

| 参数 | 首轮建议 | 对照／约束 |
| --- | --- | --- |
| Rating | 先 G、E，随后扩展 S、Q | 先观察薄弱分级与当前较好分级 |
| 日期依据 | 冻结 created_at，UTC | 保留 observed_at 与帖龄可靠性 |
| 羽化半宽 h | 90 天 | 0、45、180 天作有限对照 |
| 有效群体支持 | 先沿用 5,000 的量级 | 羽化时使用 n_eff，不直接沿用重复记录数 |
| 直榜结构 | v1 为基线，先令 γ=0 | 独立试验少量 α／γ 条件规则 |
| 画师项 | 关闭可运行 | 开启单列消融，不作为前置阻塞 |
| 个体修正 | 先做无修正对照，再启用受约束模型 | 不与大量新规则同时变化 |
| 融合 λ | 检查 0、0.25、0.5、0.75、1 | 开发验证集选择，各 Rating 可不同 |
| 类型惩罚 | 未核验 Tag 线索为 0；确认纯漫画再比较影响 | 可试 2／5／10 个 J 分值点；先检查误伤 |
| 年代软偏好 | 质量对照时关闭 | 后续单独开启 |
| 年代硬配额 | 质量对照时关闭 | 与软偏好分开实验 |
| 单榜补救名额 | 比较 0／5%／10% 的预算份额 | 合计计入 N_r，不能额外增加总量 |
| 探索名额 | 比较约 1%／3% 的预算份额 | 覆盖完整未入选池，固定种子 |

本表“预算份额”的分母是该 Rating 的下一阶段保留数量 N_r，与 v1 按原候选池计算的通道比例不同，运行记录必须明确标注。

### 13.2 小规模 Bridge 起点

一个可缩放的示例配置：

- G、E 两个 Rating。
- 选择 2016–2018 与 2024–2026 六个年份，兼顾较早时期、较新时期和跨年边界；实际选择取决于冻结输入覆盖。
- 每个 Rating、年份、六个排名区间先各取 10 张，共 720 张基础 Bridge。
- 再补最多约 240 张边界、时间未知、类型冲突与两榜分歧样本，Bridge 总量约 960 张以内。
- 每张 Bridge 初始安排约 4–6 个不同对手，实际以连接覆盖为准；另预留约 10% 比较用于重复和位置交换检查。
- 独立开发验证集可从约 400 张起步，独立验收集约 800 张起步；稀有误伤与小幅收益需要继续增加样本。

这些数量是试点建议，不是已经选取的图片、已启动的任务或确定的费用。抽样和比较预算在实验配置中单列；模型、预览分辨率和重复次数共同决定成本。

试点时间范围是独立冻结范围，各基线使用相同候选与统计定义。结果不能直接外推未覆盖年份或全库。

### 13.3 验证数据分工

| 数据 | 用途 | 禁止用途 |
| --- | --- | --- |
| Bridge 训练数据 | 建立共同尺度、类型规则和个体修正 | 作为唯一质量验收依据 |
| 开发验证数据 | 选择有限参数、比较方案方向 | 调参后仍冒充从未使用的验收集 |
| 独立验收数据 | 报告最终方案同预算效果 | 反复看结果后继续调整同一版本 |
| 主动反例集 | 诊断具体漏图／误伤 | 按随机总体样本推算全库比例 |

同一图片、近重复作品与已知关联变体不能横跨训练和验收。另做按画师分组留出的检查，评估是否主要记住了画师偏好。

验收时可以使用训练阶段已经固定的参考锚点帮助统一判断尺度，但这些参考图不计入验收样本。验收图及其比较结果不得用于重新拟合锚点、时间曲线或个体修正；否则需另建独立验收集。

分层非均匀抽样保留纳入概率 π_i。总体召回可用加权比例估计：

$$
\widehat{Recall@B}
=\frac{\sum_{i\in test}\pi_i^{-1}y_i z_i}
{\sum_{i\in test}\pi_i^{-1}y_i},
$$

其中 y_i 是独立判定的目标好图标记，z_i 是该方案是否保留该图。它是总体比例的估计，不是没有误差的全库真值。

不确定质量／类型标签不能悄悄丢弃，需复核或报告上下界。区间估计考虑抽样分层与关联作品分组，不把重复比较当作新增独立图片。

### 13.4 对照与消融

按顺序开展，避免一开始生成庞大的组合网格：

| 组别 | 目的 |
| --- | --- |
| 收藏排序 | 最简单、必须报告的基线 |
| v1 直榜与既有通道策略 | 区分原公式与通道选择的收益 |
| 分 Rating 的 v2 直榜 | 检验权重／结构调整 |
| 年内百分位直接混排 | 诊断“各年分布拉平”的影响，不作为默认最终方案 |
| Bridge 年代校准、无羽化 | 隔离跨年视觉校准收益 |
| Bridge 年代校准、启用羽化 | 检验边界连续性与泛化变化 |
| Bridge 加个体修正 | 检验年内错排是否实际减少 |
| 两榜融合，不加补救保护 | 检查平均是否稀释单榜优势 |
| 两榜融合，加补救保护 | 衡量额外召回与被替换边缘图的损失 |
| 类型适配与分镜保护的消融 | 检验主任务收益和保护误伤 |
| 年代软偏好／目标配额 | 单独报告构成变化与质量代价 |

与日期／Bridge 无关的用途、代表记录、候选范围和资源预算保持一致。不同方案产生的新特征或额外视觉读取必须计入成本。

### 13.5 晋级与停止条件

实验配置预先固定各 Rating 可接受退步幅度、精良分镜误伤上限、主要截断预算和资源上限，不能看到验收结果后改口径。

建议判定：

- 只有独立验收支持同预算召回提升，才称为“已验证提高”；点估计提高但区间跨零，记为有希望但证据不足。
- 检查优秀图召回、关键前段位置以及 G/S/Q/E 各自是否出现不可接受的退步。
- 精良分镜误伤超限、时间修正依赖缺失值误填、比较图断连或类型口径改变时，先修正相应环节。
- 如果只有年代配额开启后看起来更符合偏好，报告为构成调整收益，不能归给桥接质量校准。
- 某个模块没有稳定增益，保留关闭路径；不因方案更复杂就默认应启用。

## 14. 计算复用、工程接入与成果记录

### 14.1 分离昂贵判断与可复用计算

Bridge 图像、展示参数、比较结果和质量／类型标签按版本缓存。一次比较证据可支持多次元数据参数试验；改变审美准则、图片版本或判断协议时，重新评估复用范围。

融合 λ 或年代偏好变化通常不需要重新看图，但仍需要后台重新计算优先级、选择集合或构建排序索引。不能只排序当前前端已加载页面。

羽化宽度变化会改变参考分布与校准特征，可能需要重算统计和重新拟合；只有已有 Bridge 覆盖充分时才可复用原视觉比较。界面不能把它描述为永远零成本、即时生效。

### 14.2 建议成果结构

以下为拟议产物，不是当前已支持的 API／DTO：

| 产物 | 核心内容 |
| --- | --- |
| 固定输入与特征表 | 身份、代表观察、Rating、日期精度、原始 Tag、共享特征 |
| 类型规则与判断表 | 类型证据、分镜保护、冲突、判断来源、用途惩罚 |
| Bridge 清单 | 图片身份、抽样层、纳入概率、主动样本原因、展示版本 |
| 比较记录 | 对手、位置、判定、并列／失败原因、模型或人工来源、费用 |
| 校准成果 | 比较网络、相对分、支持与不确定性、时期曲线、个体修正版本 |
| 排名成果 | D_raw、B_time、个体修正、B_raw、d、b、F、P_type、A_era、J 及各榜名次 |
| 选择成果 | 固定成员、预算、入选入口、配额计数、回流与未满足约束 |
| 实验报告 | 参数、候选与标签版本、成本、指标区间、消融、反例和失败记录 |

中间分数有明确语义，不能用单个“最终分”覆盖全部依据。原始数值保留，显示舍入不参与截断；并列使用固定种子的稳定键，不按 ID 自然新旧打破并列。

### 14.3 兼容现有项目职责

- 数据湖与既有成果保持只读，新实验写为新成果及对应工作集。
- 来源适配器负责准确取得固定观察字段；计算层读取冻结材料。
- 引擎负责任务、成本记录、取消、恢复、产物发布和引用生命周期。
- Bridge 的图像读取与元数据计算分别申报资源，避免原来不读图的算子隐式承担视觉任务。
- 新材料升级版本，不原地改写 v1 排名 SQLite 字段与旧成果含义。
- 当前排名浏览按固定范围建立索引的架构继续复用；新排序字段需要适配后台索引及分页。
- 任何新增公共契约或项目存储改动，都按项目规则运行相应契约、静态检查与集成验证；文档完成不代表这些改动已经完成。

## 15. 必须覆盖的验证场景

### 15.1 纯计算与材料一致性

- 羽化权重非负、总和为 1、边界中点各半，过渡两端连续且导数符合定义。
- h=0、45、90、180 天，闰年、UTC 日期、单侧支持和未知日期均有明确行为。
- 固定其他输入，仅扰动羽化时间坐标，校准函数不产生人为跨年跳跃；此项是组件性质测试，不是视觉质量验证。
- 加权百分位对并列一致，n_eff 不将重叠贡献重复计数。
- 两榜归一使用同一候选总体；λ 两端能重现对应榜单的次序。
- 类型惩罚仅计入一次，精良分镜不因格数或 comic 单标签触发明显处罚。
- 一图多观察／多帖子／多通道／跨边界贡献只占一次成员名额。
- 预算、补救保护、年代目标与回流可复现，硬约束不可行时结果明确。
- 恢复、取消和来源更新不会改变已冻结比较输入或已发布成果。

### 15.2 真实质量验证

- 当前前段普通图与尾部好图。
- 典型漫画与同样带漫画标签的精良 2–4 幅／页分镜。
- 多视角、局部特写、黑白、对白框等容易被误伤的图。
- 新图低互动、观察时间未知、早期分项票数口径异常。
- 同年内原顺序被 Bridge 推翻，以及修正能否推广到未见图片。
- 某年代尖端较强但中段较弱，检查是否被一个年份常数抹平。
- 直榜与桥接榜分歧、融合后被稀释、保护名额挤占边缘好图。
- 日期边界附近与未覆盖年代的表现。
- 多个前段预算位置，而非只看前几十张或一个最终阈值。

## 16. 实验推进顺序与待定事项

| 阶段 | 完成标准 |
| --- | --- |
| E0：数据与标注口径 | 冻结候选，解决或隔离 Rating／观察时间问题，形成漫画与分镜的正反例规范 |
| E1：小样本 Bridge | 完成基础抽样、盲比较、连接检查、开发与验收划分，保存完整费用 |
| E2：年代羽化与校准 | 得到硬边界对照、连续羽化曲线和可靠回退，并完成边界验证 |
| E3：个体修正与两榜融合 | 分离年代校准与年内纠错收益，验证单榜补救和候选预算 |
| E4：年代构成实验 | 单独开启软偏好／配额，报告构成改变及质量代价 |
| E5：扩展与接入 | 在独立验收支持下扩展 Rating／时期，形成正式参数与兼容实现 |

待实验确定的内容包括：各 Rating 最终结构与系数、羽化宽度、曲线平滑强度、比较模型、Bridge 规模与补充策略、个体修正特征、类型识别阈值与惩罚、融合权重、保护名额、年代偏好范围、具体视觉模型和预算。

这些待定参数不影响先建立冻结样本、比较协议和独立验收集。第一轮目标是证明各模块带来的额外召回及其成本，再决定哪些模块进入正式版本。

## 17. 首版接入范围：仅元数据计算

按后续实施要求，首版不支持视觉判断。已接入独立可选的 v2 元数据方案，并保留原 v1 算子、参数和成果读取路径。

首版包括分 Rating 权重、时间上浮／下调、跨年羽化与加权相对表现、直榜与年代相对榜融合、类型标签线索及分镜保护、年代偏好和目标配额、预算内单榜补救与审计、分数组成和年份诊断，以及五种顺序的后台分页索引。

年代相对榜明确标记为元数据结果，不能称为经过 Bridge 视觉比较校准的总榜。Bridge 图像抽样与视觉比较、共同视觉标尺、基于视觉标签的个体修正及审美召回验证留待后续阶段。

为保护不能仅靠标签确认的精良分镜，漫画标签软降分默认 0；用户可设置有上限的实验幅度。单独的 comic 标签不扣分，2–4 格、多视角、特写与设定展示线索受到保护。标签匹配并不等于已经确认“纯漫画”。

实现决定见 [0018：MetaRecall v2 元数据阶段](../../decisions/0018-metarecall-v2-metadata-ranking.md)，操作与验证记录见 [v2 元数据阶段接入验证](../../verification/verification-metarecall-v2.md)。
