# UE 5 风格工作台

日期：2026-09-23。状态：第一阶段已实施并通过隔离验收。本文描述产品方向与分阶段范围；验证边界见[验收记录](../verification/2026-09-23-workbench.md)。

## 已确定的方向

整体前端以 UE 5 的深色视觉、编辑器标签、停靠面板、属性分组和逐级展开为主要参照。先建设公共工作台，再以美学排序完整验证，同时适配资料浏览。美学排序默认进入排名图片网格，完整保留图片比例；不同 Rating 独立，保护候选独立于排名。

首要适配基准为 **2560×1440、100% 系统缩放**，面板默认尺寸、信息密度和留白以此为准。验收同时覆盖扣除系统任务栏后的可用窗口高度；150% 缩放作为远程控制兼容场景，不作为默认设计密度。

项目仍是持久化工作空间，工作集是数据对象，工作区布局只描述呈现。不同功能没有强制业务顺序。关闭标签和收起面板不控制后端任务。

## 顶层信息架构

2026-09-27：已接入独立应用级“数据湖”编辑器，支持任务、计划与项目范围准备，见 [ADR 0039](../decisions/0039-lake-update-workbench.md)及[验收](../verification/2026-09-27-lake-updates-ui.md)。其上下文与项目模块分开；下文的项目级工作标签仍按原项目会话保存。

1. 应用菜单和项目身份：项目打开、编辑、工具、窗口、偏好设置与帮助。
2. 编辑器标签：承载正在使用的功能与内容，切换时恢复当前对象和浏览上下文。
3. 上下文工具栏：本编辑器的高频操作、排序与面板入口；展开的筛选、定位和显示参数放入右侧面板。
4. 可停靠面板：大纲、视口、详情分别承担组织、查看和解释；同一区域的面板使用标签组。
5. 底部抽屉与状态：项目资源、后台任务和异常的按需入口。

第一阶段每个项目、每个功能保留一个工作标签；重复打开激活已有标签，关闭最后一个标签回到资料浏览。项目级浏览状态及美学模块自己的草稿、选中阶段和快照独立保存。后续再扩展同类型多个工作集/阶段/快照实例，并为各实例保存独立状态；首轮不伪装成已具备多实例编辑器。

## 公共面板协议

宿主接收有稳定身份和标题的面板以及中央内容。面板可停靠左、右、底部；同位置合并为标签组。隐藏后在工作台底部显示恢复入口；工具栏末端的“显示或隐藏面板”菜单列出全部面板并以勾选表示可见性（2026-10-09），整体支持恢复默认布局。拖动分隔线调整尺寸，也支持方向键和 Home 恢复。

资料浏览右侧默认包含“检查器 / 筛选 / 定位”，项目查询按需加入同一标签组。侧栏初始宽度为 380 px；已保存的用户宽度继续保留。功能可通过公共面板 Portal 将控件放入停靠区，状态仍归原功能所有；切换标签、移动或隐藏面板不重新创建筛选控制器，不中断进行中的查询。

布局按编辑器配置保存。尺寸、位置和活动标签属于应用偏好；候选、选择、快照等业务身份属于项目会话。布局持久化复用现有编辑状态服务，保存失败和冲突使用已有恢复入口。旧布局与旧会话能够打开，不修改项目数据库格式。

停靠可通过具名菜单或拖拽面板标签完成：拖到左/右/底部区域显示蓝色落点，拖到标签之间调整顺序，Esc 取消；顺序随布局偏好保存（`order`，旧布局无此字段时按声明顺序）。独立浮窗和跨显示器仍属于后续扩展。位置规则与内容组件解耦，功能模块只使用公共 UI 与 SDK。

## 视觉与组件

- 近黑窗口背景；深灰面板；较亮的折叠标题；凹陷的输入区域；蓝色用于活动和选中状态。
- 颜色按 background、title、panel、header、recessed、field、line、text、muted、accent、danger 等职责统一管理。
- 紧凑工具栏、2–3 px 控件圆角、细分隔线与窄面板间隔。主要信息保持可读，不依靠大标题和重复统计卡片占用画布。
- 层级数据用树，参数用对齐属性行，图片用规则网格，执行记录用列表。不同用途具有相应组件结构。
- 表单按主题折叠，并在标题提供简短摘要。高频和必要操作保持可发现；高级参数单独展开。
- 活动面板、焦点、选择与后台执行状态分别表示。键盘可以操作标签、菜单、面板恢复与分隔线。

配色核对了本机 UE 5.8.2 的 `Engine/Source/Runtime/SlateCore/Private/Styling/StyleColors.cpp` 默认值：背景/标题 `#151515`，面板 `#242424`，标题分组 `#2F2F2F`，凹陷区 `#1A1A1A`，输入框 `#0F0F0F`，输入描边 `#383838`，正文 `#C0C0C0`，主色 `#0070E0`，非活动选择 `#40576F`。辅助文字采用适合当前中文界面的灰度。这些角色集中在 `packages/ui/src/styles.css`。

组件形态对照同目录的 `StarshipCoreStyle.cpp`（Docking.Tab、Docking.MajorTab、SlimToolBar）以及 `EditorStyle/Private/StarshipStyle.cpp` 的详情分类样式：活动标签与面板连成一体，常用操作按组组织，视图模式通过下拉切换（美学排序已改为视图页签，见下文），大纲行紧凑，属性使用成对字段和分隔线。实现使用项目自己的 React/CSS 和现有图标；没有复制 Epic 的源文件、字体、品牌图标或图像资源。上述本机引擎文件不随仓库分发。

资料浏览工具栏保留“筛选”和“定位”入口；点击筛选直接激活右侧 Rating / Tag 表单。原筛选草稿、查询语义和缓存复用保持兼容。预览尺寸、图片 ID 和排名定位归入“定位”；项目查询使用竖向字段布局。图片、侧栏和查询内容各自响应所在区域的滚轮，分页与全局状态栏保持可见；窗口不使用超过视口的固定最小内容高度。新建评审按输入范围、评审标准和执行预算分组，原有值与创建行为保持兼容。

## 交互与组件补充（2026-10-06）

- 菜单项支持分隔线、勾选和快捷键提示；对象行、面板标签、编辑器标签与图片卡片提供右键菜单，复用“⋯”菜单的操作。WebView 自带右键菜单仅保留在文本输入和选中文本上，Shift+右键可临时调出。
- `title` 提示由 `TooltipLayer` 统一绘制为编辑器样式；调用方继续使用 `title`。
- 各工作台的状态内容通过 `WorkbenchStatusTarget` 合入全局状态栏，界面底部只保留一条状态栏。
- 快捷键：Ctrl+Tab / Ctrl+Shift+Tab 切换编辑器标签，Ctrl+W 关闭，Ctrl+Space 打开项目资源，F5 / Ctrl+R 刷新项目数据而不重载 WebView；资料浏览中 Alt+←/→ 与鼠标侧键在浏览范围之间后退/前进（会话内历史）。
- 下拉框使用可定制 select（`appearance: base-select`），不支持的运行时回落为原生列表；复选框和单选框统一样式。数字框可左右拖动调值（Shift 慢、Ctrl 快，遵守 min/max/step），单击仍为文本编辑。
- 参数页采用属性行：名称列宽度可拖动（本机记忆），偏离默认值的参数显示“重置为默认值”。
- 本会话内观察到的项目任务结束时在状态栏上方通知；失败通知需手动关闭。
- “新建数据湖更新”作为数据湖工作台的可停靠面板打开（非模态，仍为 `role="dialog"`），可与任务表同屏。
- 数据表格支持悬停行、斑马纹和拖动表头边缘调整列宽（双击恢复）。颜色统一由 `packages/ui/src/styles.css` 中的角色变量提供。

## 美学排序首轮

默认视图为排名浏览。通过 SDK 加载有界任务列表，从已发布拟合快照读取每个 Rating 的有界图片页；没有快照时提示生成路径，不展示模拟榜单。

大纲组织评审阶段和离线任务。详情随选中图片显示 Rating 内或分量内名次、并列区间、曝光、稳定性诊断、保护状态和证据来源。统计位置不是名次，未知值不能当作零或稳定。图片使用现有媒体服务与释放机制。

提供从已接受证据生成离线快照、查看批次、创建评审阶段、冻结标准查看、保护复核和筛选派生工作集。复核不改变统计分数。派生使用后端筛选及固定复核水位，不将浏览器当前页误当作全体结果。

新建评审按需打开配置，复用设置中的模型和 System Prompt；不添加全局 User Prompt。创建冻结与开始模型调用仍为两个明确操作；网络不确定时保留幂等键。结果不明的付费批次只通过原有显式重试入口处理。

评审执行页将统计与用量、冻结配置分别放入右侧“阶段状态 / 冻结标准”，中央保留阶段操作、批次与图片证据。排名页已有右侧详情分组，任务仍从底部按需打开。

全局保存提示同时纳入应用偏好和项目草稿，避免布局仍在等待写入时显示已保存；桌面窗口关闭继续使用 SDK 的全量 flush。

后续阅读体验已扩展为连续看图、侧栏复核与已发布快照对照，见 [ADR 0029](../decisions/0029-aesthetic-reading-and-review.md)。网格大小与每页数量独立设置，大图支持前后切换、缩放和平移，右侧通过“详情 / 评审依据 / 保护复核”切换；复核草稿随图片保存，保存后可直接处理下一张。

2026-10-09：美学排序的“排名浏览 / 评审阶段 / 保护复核 / 实验对照 / 实验配置”由工具栏下拉改为工具栏左端的视图页签。各视图替换整个中央区域并保留各自的布局配置，因此它们是同级页签而非可停靠面板；会话字段 `view` 不变，旧会话照常恢复。排名快照行第二行显示估计器参数和来源阶段，悬停显示完整设置；生成快照在名称未手动修改时以“来源阶段 · 参数”命名，便于同一阶段的多份快照对照。来源阶段下拉框对已归档阶段标注“已归档”。

实验对照首版可选择两份已有快照，查看同图百分位变化、提名分歧及 Rating 可比性。后续已通过“实验配置”接入变体批量配置和结果导航，并在评审阶段增加基础预检、候选异常处置和创建恢复，见 [ADR 0030](../decisions/0030-aesthetic-execution-ui.md)。有容量上限的按轮次动态采样、追加计划及有效性摘要已接入，见 [ADR 0032](../decisions/0032-aesthetic-adaptive-sampling.md)；真实 System Prompt 质量校准与目标容量验收仍未完成。已有相关后端能力不等于质量验收完成。
