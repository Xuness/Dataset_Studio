# 0.9.1 排名工作集浏览验收

日期：2026-09-10。对应[实现决策](../decisions/0012-ranked-workset-browsing.md)与[阶段清单](../plans/ranking-browse-v0.9.1.md)。

## 使用方法

1. 打开已有的排名工作集。浏览器默认选择“保存时的榜单顺序”，图像卡片显示分级、主排名、补救排名及相应分数；单图查看也保留这些信息。
2. 在“浏览排序”中选择“主排名”“补救排名”或“排名输入顺序”，旁边单独选择升序或降序。普通 Danbooru ID、图片身份排序仍可用。
3. 在“从图片定位”输入 Danbooru ID，点击“从此图开始”或按 Enter。目标图片成为第一页第一项，然后可继续翻页。
4. 改变查看方向或排名依据后，仍使用填写的 ID 作为起点。点击“重置起点”，即可沿当前方向从整张榜单开始。
5. 排序、方向、起点和已打开的页面随项目保存。重命名工作集后也保留位置。

这项定位改变查看位置，不改变工作集成员。“选择全部范围”仍选择整个工作集；只选择当前页可使用“选择本页”。例如从主排名前五名保存的工作集，改按补救排名查看时也始终只包含原来选出的那些图片。

名次在各分级内计算；降序沿原榜单顺序反向查看。同一个 ID 对应多张范围内图片时，定位当前顺序中的第一个匹配成员。未知名次显示“未排名”，缺失分数显示“未评分”。
