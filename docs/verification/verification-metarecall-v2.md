# MetaRecall v2 元数据阶段：接入与验证

日期：2026-09-13。状态：代码已接入，并完成工程验证。视觉判断与 Bridge 视觉校准未接入。

开始开发前，工作树只有 v2 实验设计文档未提交；已先形成本地提交 `f886bd2`，确认工作树干净后进行实现。

## 使用入口

在“计算工具 → Danbooru 元数据排名 → 筛选方案”中选择：

- **MetaRecall v1 · 旧方案**：保留原算子、参数和评分方式。
- **MetaRecall v2 · 元数据多阶段**：使用分级公式、年代羽化与可调融合。

切换到 v1 后，再回到 v2，会恢复之前的 v2 参数；当前方案和草稿也可跨页面重载保留。修改参数需要启动新任务，旧成果保持固定。

v2 支持五种查看顺序：筛选优先级、年代相对排名、直算排名、融合排名和输入顺序。保存为工作集后，这些排序继续使用后台索引分页，而非只排序当前页面。

## 首版能力与默认值

| 项目 | 行为 |
| --- | --- |
| 分 Rating 参数 | G/S/Q/E 独立保存时间上浮、时间下调、负票与年代榜融合权重 |
| 保守初始值 | 时间上浮 0.30、时间下调 0、负票 0.08、年代榜权重 0.30；这些不是经视觉验证的最优值 |
| 时间羽化 | 默认半宽 90 天，支持 0–180 天；0 为硬边界对照 |
| 加权统计 | 使用同 Rating、相近帖龄的年代加权中位秩、有效样本量与支持量收缩 |
| 信息不足 | 时间、帖龄比较或有效样本不足时回退，并保留逐图和年度诊断 |
| 融合 | 两榜在同一 Rating 总体上转为百分位，再按权重融合 |
| 类型规则 | 冻结完整 Tag，记录扩展漫画线索及构图保护；漫画标签软降分默认 0，可调上限 10 分 |
| 分镜保护 | comic 单标签不扣分；2–4 格、多视角、特写及设定展示线索受保护，不以标签声称已确认纯漫画 |
| 年代偏好 | 与融合分分别记录，偏好分同样使用羽化 |
| 年代目标 | 按实际上传年份计数，每个 Rating 分别执行；严格目标不可行时报错，允许回流时记录实际回流 |
| 保留预算 | 仅排名默认不分配名额；生成候选集默认保留各 Rating 合格候选的 33.3% |
| 补救与审计 | 默认直榜独有补救、年代榜独有补救各占保留预算 5%，审计占 3%；不增加总预算 |
| 逐图说明 | 显示直算原分、两榜百分位、融合分、类型调整、年代偏好、各榜名次和回退原因 |
| 年份诊断 | 显示候选分布、最终前 1% 分布、保留数量、回退及类型保护计数 |

时间与年代参考关闭时，融合使用直算榜；手动设置的年代偏好仍独立生效。标签降分只有元数据依据，不能可靠区分所有“纯漫画”和精良分镜，所以默认关闭，并提供明确的保护与实验参数。

“年代相对榜”不是经过 Bridge Image 视觉比较校准的总榜。本次没有调用视觉模型，没有建立视觉质量标签、好图概率或学习型跨年代审美曲线。

## 兼容性与材料

新增独立算子 `danbooru.metarecall_v2`，旧 `danbooru.metarecall` 保留。参数中的 v2 扩展为可选字段，旧参数序列化不自动增加该字段。

v2 输入和评分文件使用材料版本 2；旧文件保持版本 1。新程序读取两版材料，本次未增加项目数据库迁移。v2 增加标签快照、分数组成和直算／融合名次，仍通过既有任务冻结、断点、校验及发布链路生成成果。

v2 固定范围索引增加直算和融合顺序；旧成果和 v1 索引继续按原身份读取。实现决定见 [0018](../decisions/0018-metarecall-v2-metadata-ranking.md)。

## 真实元数据的补充验证

实时数据索引当轮被既有 Python 进程占用，试跑返回 SOURCE_BUSY；未处理该外部进程，也未强行复制其打开中的数据库。

改用项目已经固定的真实排名输入，按原 ordinal 等距抽取 1,024 条，在独立临时目录建立派生输入，并交给实际 Rust worker 计算。1,024 条均完成评分，核对了有限数值、分数组成及各 Rating 保留预算。

这次派生材料保留原热度、时间等值；完整 Tag 未存入旧材料，因此明确标记为不可用，并保持漫画标签软降分关闭。该验证不覆盖实时 DuckDB 投影或真实完整标签读取；后者的读取链路已由隔离夹具验证。

原固定文件用只读连接读取，并检查大小、修改时间保持一致；没有额外重算大型原文件哈希。未重跑生产全库、未写入原 Studio 项目，也未进行视觉判断。

本机证据位于 `.local/reports/metarecall-v2-integration-20260913/`，包含日志、集成报告、界面截图和真实固定元数据试点记录。真实数据与生成材料不进入 Git。测试目录的逐项清理命令被自动策略审查拦截（返回 blocked by policy），删除未执行；证据已归档，临时目录保留。

## 后续实验边界

当前检查证明计算、存储、兼容与交互链路可用，不证明新公式已经提高审美召回率。下一步可在固定候选范围内比较不同 Rating 参数、羽化宽度、融合权重及年代偏好；视觉 Bridge、个体视觉修正和独立审美验收仍按总体实验设计另行推进。
