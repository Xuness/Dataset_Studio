# Pixiv 公开采集生产验收

日期：2026-10-03。基线为阶段 1–3 之后的公开采集、增量复查、周期调度及现有界面接入。设计依据见 [ADR 0053](../decisions/0053-pixiv-public-operation-and-incremental-refresh.md)，操作入口见[来源采集](../architecture/source-collections.md)。

## 交付范围

现有数据湖工作台可以创建、预览、暂停、续跑、取消和复查 Pixiv 作者／作品任务，查看排除项、实际缺口、快照沿用与发布进度。周期计划具备修订保护、启停和幂等创建，复用既有后台进程和资源调度。相同运行意图合并；待检查的旧任务不阻止显式新建复查。

现有浏览、元数据和查询页面支持 Pixiv，提供作者／作品筛选、作品类型、原样标签、页序和来源元数据。设置中的数据湖 API 管理公开账号、加密会话导入、验证和清除；原有下载设置与位置迁移入口也包含 Pixiv。

归档版本为 2，在线索引版本为 3，采集控制契约为 2，控制数据库版本为 10。v10 修复早期开发控制库缺少可重建计数与发现边的情况，保留原有任务、凭据和归档事实。

## 完整性、恢复与既有数据保护

- 对固定水位 913 的全部 275 个物理对象重新读取字节并核对 SHA-256，全部通过。
- 只使用正式不可变归档建立独立在线准备库：388 个原始响应通过完整性验证；18 张表与同水位的正式索引逐表计数、摘要完全一致。
- 正式水位推进至 916 后再次比较，固定水位 913 的结果仍完全一致。准备库通过正式 `cleanup` 命令回收并释放参考租约，没有切换正式索引指针。
- 在水位 916 通过原生 SDK 分页读回全部 125 个作品和 276 个媒体条目，每个作品清单均为 `ready`，每个媒体条目都有发布绑定。作者筛选返回 275 个去重资产；多页作品筛选、原始 JSON、历史观察和 3 张解码预览均通过。
- 真实任务执行过暂停、确认进程退出及恢复。离线测试覆盖进程重启、归档已提交但控制未回放、目录批量沿用的中断重放、迁移与损坏媒体包检测。
- 新增 Pixiv 前保存控制库一致性备份。与升级后的控制库逐表比对，18 张既有控制表的原有行保持一致；新增湖、调度和设置允许增加新行。Danbooru、Yandere、Gelbooru 的既有任务和凭据保留。

## 尚需真实凭据的验收与范围边界

公开访问的固定范围抓取、补齐、重复执行、归档恢复和 Studio 接入已验证，可用于公开内容生产。`visibility_verified=false` 仍明确保留，不等于账号能够看到的全部内容已被验证。

用户尚未提供登录凭据，真实登录、会话过期后的恢复，以及 R-18／R-18G 等显示条件仍待该输入。加密导入、等待凭据、清除、错误分类及恢复控制已有离线与界面测试。

本次真实作者样本没有 Ugoira，也没有向外扩展作者关系。Ugoira 的帧表、ZIP 与封面归档，以及关注、收藏、推荐关系的分页和预算已有离线回归；它们的真实来源覆盖和持续大规模吞吐不在此次证明范围。搜索、排行榜、新作发现入口、浏览器辅助登录以及动画完整播放属于后续扩展。
