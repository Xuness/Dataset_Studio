# 排名工作集未排名图片置底验收

日期：2026-10-04。规则见 [ADR 0058](../decisions/0058-fixed-ranking-membership-recipes.md)。

主榜、补充榜、直接榜和融合榜统一先显示具有当前榜单名次的图片，再显示未排名图片；正序和倒序都保持未排名部分在末尾。各部分内部继续按 Rating、名次和序号排序。输入顺序和显式帖子/资产 ID 排序保持原有语义，工作集成员和原始分数不变。

直接读取路径按两部分分别使用原始索引范围查找，跨部分翻页不重新扫描前方成员。复杂查询的派生索引按相同规则建立位置书签，倒序总榜位置在两部分内部各自换算。显示顺序版本同时约束游标和派生缓存；旧分页游标失效时清除当前范围的旧页面缓存并回到第一页，旧起点游标则按保存的帖子 ID 或排名数值重新定位。

## 真实范围

使用现有「Danbooru全湖元数据排名-v2」工作集，共 **11,624,906** 张图片。四种榜单均有 **3,628,869** 张已排名图片、**7,996,037** 张未排名图片。只读取已有成果和工作集，没有新建工作集或重新评分。

对四种榜单的两个方向分别核对：首屏 48 张、最后一张已排名图片、跨界后的前 48 张未排名图片、最后一张图片及无后续页。所有序号与原始分数文件的独立 SQL 对照一致。API 首屏耗时为 **18.43–27.32 ms**，派生排名索引构建数保持 **0**。

测试使用 Release 引擎，SHA-256 为 `e3ffce3ff0bfcfc9e8d9d5e265511a893568471155086ad72872aa0783691d7a`。其他自动测试完成后执行本次读取；未清空操作系统缓存，计时不包含缩略图下载或解码。

## 回归

- `pnpm check` 通过，包括 Rust、Clippy、契约及 424 项数据湖测试。后续浏览器恢复处理单独重新通过类型检查和完整 lint。
- 27 个集成入口通过。整套命令完成前 11 个入口；新增交界测试修正无帖子 ID 样本的定位前提后，从排名浏览入口继续完成其余 16 个。产品后端在两个批次之间未改变。
- 排名浏览集成共 28 项检查，包含直接工作集与物化查询结果的双向未排名置底、交界翻页、数字定位及可用帖子 ID 定位。
- 浏览器验收共 23 项检查，包含旧分页游标返回新首页、旧数字起点重新解析并保留输入，以及既有排序、翻页、刷新、选择、筛选和窗口布局。
- 存储测试以混合 Rating、空分级、大量缺失名次和稀疏成员对照独立排序；验证总榜交界位置、五种顺序、正反向完整遍历、旧缓存拒绝及有界分页。

本机报告、日志、界面截图和清理回执位于 `.local/reports/ranking-unranked-last-2026-10-04/`，不随仓库分发。原始排名材料不需要迁移；旧格式派生缓存通过正常缓存流程重建。
