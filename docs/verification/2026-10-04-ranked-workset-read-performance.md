## 存储与固定语义

本轮四个工作集均未写入 `collection_member_legacy`，额外派生排名索引构建数始终为 **0**。全范围成员描述 JSON 为 **490 字节**；这只是描述本身的大小，项目仍需保存对象、结果和引用等少量元数据。原输入和分数文件继续由所有工作集共享，不为每次保存或 Rating 条件复制千万条成员，也不再新建原有约 3.18 GB 的工作集排名索引。

最终保留「Danbooru全湖元数据排名-v2」，全部使用新的成员引用；本轮其他三个工作集和五个筛选结果通过正常 API 清理。未被引用而仍处于就绪状态的内部排名结果为 0。

完整流式 SHA-256 校验确认原始三份成果文件与发布时摘要一致：排名输入 10,507,726,848 字节，评分文件 6,459,887,616 字节，摘要 JSON 8,665 字节。保存、筛选和读取没有改写排名材料。

本次直接读取覆盖保存的排名条件及冻结 Rating 细化。当前标签、当前帖字段和其他复杂组合继续走现有成员构建路径；不把它们的性能描述为本表的 Rating 筛选耗时。未知组合的首次精确计数也可能需要读取更多索引或数据页。
