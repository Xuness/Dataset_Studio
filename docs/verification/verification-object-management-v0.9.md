# 0.9 对象管理与选择撤销验收

日期：2026-09-10。开发版本：0.9.0。对应[实现决策](../decisions/0011-object-management-and-selection-history.md)与[范围清单](../plans/object-management-v0.9.md)。

## 使用入口

| 需要做什么 | 入口与行为 |
| --- | --- |
| 管理对象 | 数据湖、工作集、成果、查询和任务条目旁的“⋯”；详情在右侧相邻的“属性 / 管理”标签间切换。项目菜单及侧栏底部也有当前项目入口。 |
| 修改名称与备注 | 管理页编辑后明确保存。名称不改变图片身份、目录或历史计算文件；数据湖改名保留当前浏览页与位置。 |
| 取消数据湖关联 | 数据湖管理页“取消关联”，只作用于当前项目。展开侧栏“已取消关联的数据湖”可以恢复。使用该来源的后台任务或查询需要先结束。 |
| 删除工作集与计算结果 | 管理页显示具体引用及跳转入口，满足条件后删除。已固定的任务输入独立保留；结果文件被占用时显示待清理，可重试。 |
| 查看工作集来源 | 管理页提供原范围、筛选或生成参数及“它来自哪里”；“使用它的对象”展示后续使用者，支持分页与跳转。 |
| 查找工作集与结果 | 列表支持名称、备注或身份查找、排序和分页。排名列表先筛选成果类型，再分页。 |
| 整理查询与任务 | 查询定义可删除，当前条件保留为草稿。任务支持状态筛选、搜索、归档及恢复；已结束且成果已释放的任务可清理固定输入及受控暂存。 |
| 复用参数 | 历史任务与成果可“复用参数”；基础工具和排名可创建、应用、重命名、修改备注、更新或删除项目内预设。应用后需确认当前输入范围并手动启动计算。 |
| 打开文件位置 | 项目及成果的管理页提供复制路径和打开位置，大型结果直接定位原文件；完整路径可展开查看。 |
| 撤销与重做 | Ctrl+Z 撤销选择，Ctrl+Y / Ctrl+Shift+Z 重做，也可使用工具栏和“编辑”菜单。输入框保留文字撤销。 |
| 调整历史上限 | “设置 → 编辑与撤销”，默认 50 步，允许 0–200 步，0 关闭历史。历史随项目保存，可清空当前项目历史。 |

撤销涵盖图片选择、清空、范围替换、添加、移除和交集。删除对象、清理文件和提交任务不属于选择撤销。历史保留恢复选择所需的查询与成果材料；清空或裁剪历史会解除相应保护，当前选择保持不变。

## 实现与兼容

数据库从 v1–v8 顺序升级至 v9，升级前保存含已提交 WAL 的一致备份。清单 format_version 仍为 1，注册表仍为 v2。项目显示名保存在数据库中，project.json 保留创建时名称。升级保留已有选择，选择历史从之后的新操作开始。

选择历史保存成员净增删差量、选择基底及引用；单次点击不复制查询基底的全量成员。历史支持事务修订检查、重开恢复、分支编辑和连续历史裁剪。十万成员基底的单次编辑检查验证其 SQL 工作量和差量记录保持有界。

对象查询与引用关系通过后端游标分页。工作集、查询和任务删除保留必要的历史记录及请求身份，重放旧请求不能重新创建已经删除的工作集或任务。原始数据湖保持只读；取消关联同时检查普通读取和预览缓存访问。

Tauri 打包副本改名为 studio-engine-sidecar，避免桌面构建复制旧副本并覆盖 Cargo 生成的 studio-engine.exe。检查脚本先准备副本，再验证桌面宿主。
