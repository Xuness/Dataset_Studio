# Delete/Ban 标记与原图下载验收

日期：2026-10-01。源码基线：`00af72f`。

## 行为与恢复

三站更新共用下载流程不再仅凭 `is_deleted` / `is_banned` 跳过图片。API 提供符合既有地址规则的原图时，按原保存配方尝试下载；这些标记继续写入原始元数据和结构化观察。

旧 `source_deleted` / `source_restricted` 结果通过既有“重试未获取项”刷新元数据后重新下载，成功项目不重排。没有可用地址、当前不支持的格式，以及服务器实际返回的 403/404 等各自保留对应处理。接口、数据格式及暂停语义不变。决定见 [0049](../decisions/0049-source-status-and-media-availability.md)。

## 正式任务只读检查

13:40 的暂停快照：已保存 1,189、待处理 5,102、未获取 109。未获取原因为 Delete 58、Ban 2、无地址 30、不支持格式 19。

用新下载检查器对这 109 条记录作有界只读检查，46 条能进入下载流程，43 条没有可用地址，20 条格式不支持。多出的一条格式不支持此前被 Delete/Ban 的提前判断遮蔽。这只是地址与策略检查，不代表 46 条远端下载均已成功。

## 真实原图端到端验证

从暂停任务取两条已有原图地址的 Delete 帖子元数据，在 `.local/test-runs/` 的独立湖重放；图片使用生产 CDN 传输、来源 MD5 校验、WebP Q95 / M4 / 最长边 2048 配方、归档和在线投影。

两张原图均通过来源 MD5 校验；从归档读回的输出通过 SHA-256 校验和完整 WebP 解码。原始元数据字段与输入记录一致，Delete/Ban 标记保留。正式任务的状态、计数、任务定义及 109 条未获取记录摘要在验证前后相同。Ban 且有原图地址的分支由三站合成回归覆盖，本轮正式 Ban 样本没有可用地址。
