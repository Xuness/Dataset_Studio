# 0.4 工具、成果与读取基础层验证

日期：2026-09-08。软件 0.4.0；项目清单 v1、项目数据库 v4、应用注册表 v2。

状态：已完成。代码、独立引擎、并发、原生窗口及日常项目升级逐项核对均已通过。

## 实现范围

前端提供显式模块注册和五个入口：资料浏览、查询、计算工具、项目成果、读取与缓存。清单与确定性整数乘加共用注册、参数校验、输入冻结、独立执行器、重试和发布协议。

成果具有身份、类型、版本、覆盖、文件校验和依据，支持多输出、类型化分页、派生字段查询、再次消费及受引用保护的释放。查询和工具草稿通过串行 CAS 自动保存；项目会话验证范围、焦点和位置，正常关闭等待保存，恢复不自动运行。

来源读取使用优先级、取消和预算端口。预览共享生成，按索引位置批读，并保存到独立 SSD 缓存；界面可查看统计、调整配额和启动分批清理。

## 测量与范围

| 样本 | 结果 |
| --- | --- |
| 12 张合成 PNG，首次生成 / 暖缓存 | 267 ms / 27 ms |
| 同一合成对象 12 个并发 HTTP 订阅 | 1 次来源载荷读取，1 次生成 |
| 96 张合成图片，12 项一组 | 1,868 ms；最大媒体批次不超过 16，预留峰值未超预算 |
| 排队的实际包读取取消 | 14 ms 内结束；打开包 0、源载荷字节 0、生成 0 |
| 20,000 行整数成果 | 捕获、冻结、执行和发布 23,018 ms；派生查询 405 ms，精确命中尾部 10 项 |
| 一个指定真实对象 | 195,706 字节；首次预览 905 ms，暖缓存 4 ms；原始观察宽度 2480 与记录、观察和版本匹配 |
| 四个真实索引对象，2 MiB 总预算 | 实际 720,678 字节；首次 1,142 ms，暖缓存 14 ms，重启后 9 ms；命中均无新增源载荷读取 |

这些数值来自本机 Debug 构建，区分应用缓存冷暖；没有清空操作系统或设备缓存。合成图片及整数目录不是全湖样本。真实读取使用显式身份，按主键只检查八条候选索引记录，最终选择四项，没有媒体目录扫描。缓存 D 盘确认为 NVMe SSD；E 盘是 Windows 未报告介质类型的 USB 存储。本轮没有证明冷机械盘吞吐或千万级全量处理表现。

对应的引擎峰值工作集分别为：96 张合成图片 25.2 MiB、两万行标量 26.3 MiB、四项真实读取 37.7 MiB；不包括 WebView、独立执行器或操作系统页缓存。四项真实读取的来源读取与校验累计 11 ms、解码累计 1,332 ms、生成队列等待累计 891 ms；并发累计值不能直接相加为墙钟时间。暖缓存与重启后的四项请求均命中缓存。

## 验证入口及保留边界

`pnpm check` 包含类型、依赖边界、契约漂移、格式、Clippy、Rust 测试和 SDK 协调测试。集成入口覆盖原有链路、范围、工具、资源及标量规模，日志保存在 `.local/logs/phase4-final-*.log`。指定读取可通过 `tooling/verify-reads.mjs` 复现。

单个整数列采用有模式 JSONL 和 SQLite 类型化投影，没有声称 JSONL 是物理列式文件。宽表、向量、完整模型运行环境、第三方动态插件、复杂布局编辑及全湖长期压测仍按实际需求扩展。异常终止只恢复此前已落盘的草稿；资源准入和协作取消不是整个进程内存或系统 I/O 时延的硬保证。
