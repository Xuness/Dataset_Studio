## 修改与正式队列恢复

- 灰度/RGB ICC 兼容、透明通道保留、LAB A 通道区分；自定义处理版本记为 4。
- 色彩转换错误限定到单张，下载原件保留；已完成的其他图片仍可发布。
- HTTP 404 限次自动重试；一分钟累计 8 次时，共享图片通道冷却至少一分钟；不把它计成已经确认的 429/503 限流。
- 显式重试复用可用元数据与断点；缺失地址/观察、来源删除/受限或 404 尝试耗尽时再刷新 API。批次幂等键包含执行代次，重复失败可正确再次记账。
- 前端提供常见原因说明、原代码提示，以及待刷新元数据和需要检查筛选。

在执行锁和控制库事务内，逐条验证旧归档观察 ID 与当前待刷新队列一致，备份全部被修改行，再把 115,585 条记录恢复到待下载。没有下载或发布正式任务的新图片；抽样验证在隔离目录进行。

恢复后：已保存 **123,134**，待下载 **120,639**，待刷新元数据 **0**，未获取 **27**。任务保持暂停，执行代次、定义、完整内部游标、原始记录及保存参数未改变。共享流水线设置仍为修订 10。可在原任务点击“继续”；原范围剩余元数据扫描会继续。
