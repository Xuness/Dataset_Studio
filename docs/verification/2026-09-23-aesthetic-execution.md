## 实际验证

pnpm contracts、pnpm check 和 pnpm build 通过。check 包含 185 项 Rust 测试、10 组客户端基础检查及 4 组媒体检查。最后的前端恢复处理修改后，重新通过 typecheck、lint、build 和全部相关界面回归；Rust 与后端代码未再变化。

pnpm test:integration 的 20 个隔离脚本全部通过，包含评审、离线分析及 R0/R1 恢复。新增存储测试验证稀疏状态的 64 项键集分页、序号边界、阶段隔离、查询计划使用新索引，以及 v3 付费证据备份与 v4 升级；原有 v1/v2 升级测试继续通过。

界面共 27 组通过：新工作流 8 组、原评审 3 组、原工作台 16 组，均无 pageerror。入口：

- tooling/smoke-evaluation-workflow.mjs
- tooling/smoke-aesthetic-ui.mjs
- tooling/smoke-workbench-ui.mjs

新工作流使用 16 张同 Rating 合成图片和本机 mock，经真实 SDK、HTTP、SQLite 执行两次模型模拟调用。先接受含两张不可评判图片的批次，再从界面排除一张、安排另一张重评；重评保存时不派发，显式开始后与同 Rating 对手重新比较，最终带一项排除完成。

三个故障用例都在服务端成功后截断返回：阶段创建、候选处置和实验定义。重载后请求内容与幂等键一致，阶段/处置/实验不重复。导航草稿随请求保存，恢复后能回到对应操作位置。对已建成阶段尝试放弃会被拒绝，原请求继续保留。

Davidson 与 Borda 使用同一冻结证据，重复运行仍只有两个离线任务；实验、排名和对照导航不增加模型调用。页面验证以 2560×1440、100% 为主，另检查 1707×928 CSS 视口；原工作台回归继续覆盖其已有的缩放和尺寸矩阵。截图等待阶段状态及图片显示。
