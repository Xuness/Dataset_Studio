## 保留的边界

- 查询协议最多 8 个来源、12 个 AND 条件，界面当前编辑单湖定义；只支持身份升降序，能力目录不会声明未实现的元数据排序。
- 结果每页最多 128 项；前端保留有界页面和最多 128 个导航游标。全选通过引用完成；单项修改仍限制每次最多 1000 项。
- 原生查询每批最多 512 个身份、256 MB 内部内存预算、1 线程、禁止临时溢写。每来源 600 秒使用协作中断；较大的元数据连接可能明确返回资源不足。该预算不是整个引擎或窗口的内存上限，操作系统 I/O 也没有硬响应时限。
- 来源版本是读取事务、水位与末端检查，不能当作跨库原子历史快照。来源变化后直接使用旧查询结果需要重算；已固定成员不变，元数据字段值没有完整冻结。
- 结果被选择、工作集或任务引用时拒绝释放；删除成员后 SQLite 空页可复用，数据库文件未必立即缩小。
- 项目关闭在当前引擎内生效，尚未实现多客户端各自独立的视图租约。来源位置共享范围是当前应用注册表。
- 本轮只完成开发模式交付，没有生成发布包或安装器，没有进行真实全湖压测。
