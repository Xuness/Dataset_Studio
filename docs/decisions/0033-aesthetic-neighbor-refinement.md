# ADR 0033：预算内邻近细排与加速 Davidson

日期：2026-09-24。状态：已实现并完成本文范围内验证。继承 [ADR 0032](0032-aesthetic-adaptive-sampling.md) 的不可变轮次、身份、Rating 隔离、预算、恢复和证据水位约束。

## 背景

5 万与 150 万完美评审模拟表明：比较图连通不等于唯一确定总排名；数值收敛不等于名次正确。旧动态模式的位次变化与残差门槛不是经过校准的置信区间。默认正则化和求解速度同时限制了低偏差拟合。目标仍为全体图片的相对排名，不因低分而剔除，也不把精英提名加进分数。

## 版本与兼容

- `balanced` / `adaptive` 保持 `connected_rounds_v1`，已有阶段、已有计划和已经派发的轮次不随升级改变策略。
- 新 `refine_balanced` / `refine` 使用 `neighbor_budget_v2`。前者均匀曝光后停止，后者按预算分配后续比较。创建或显式追加计划时冻结版本；版本与模式不匹配时拒绝启动及规划。
- 新模式通过已有 SDK 创建与追加入口接入。追加计划仍只保存为 ready，不发送请求。配置、Prompt、模型、原始回执及旧快照不改写。跨版本追加清除继承的稳定检查次数。
- 新策略存在噪声条件上的取舍，因此保留原来的新建采样默认值（adaptive、最低 2、最高 8），两种细排作为可选项。追加对话框优先沿用当前阶段的模式。新估计器可独立用于原策略的已有证据。
- 新诊断 `rank_sensitivity` 为可选 JSON 字段。旧检查点不补写，读取时缺省为空；无需数据库 DDL 升级。
- 本轮算法验收时的生产护栏为 10,000 图 / 20,000 批接受证据，150 万实验只扩大隔离副本。后续按用户要求的 1000 万数量准入调整见 [ADR 0034](0034-aesthetic-ten-million-admission.md)，不改变本轮模拟的验证边界。

## 分组与预算分配

前两轮沿用跨分量、跨批次连接规则。连通且全体百分位可比较后，按当前估计名次划分宽度 0.002 的区间，每轮用种子改变区间偏移并在区间内混排，组成最多 16 图批次。随后按最低曝光和种子重新排列批次；输入显示顺序另行打乱。缺口用尚未达曝光上限的候选补足，尾批重新均分。全程禁止同轮重复、跨 Rating 和超单图上限。

`refine_balanced` 以最低曝光及比较连通为完成条件。`refine` 在全体可用候选至少达到 max(4, 配置最低曝光) 后，把后续目标按“整批比较敏感度 / sqrt(曝光+1)”排序，选取前 75%，并对其余候选执行确定性的 1/8 轮换抽查。这只是待验证的信息价值代理，不声称达到信息论最优。达到预算或曝光上限时停靠并保留原因，可生成快照、复核或显式追加。

敏感度使用整批梯度的离散程度、对角曲率及正则化影响估算，再映射到百分位范围。整批为观测单位，16 图展开的 120 对不能当成独立样本。它忽略图片间协方差及模型系统偏差。5 万混合噪声预筛发现，整体覆盖率高仍可能伴随“窄区间候选”上的明显误判，因此 **不以敏感度或位次不再变化自动宣布动态精度满足**。新动态模式 `stable` 保持 0；原有 `rank_tolerance` 仅保留兼容及位次变化诊断，前端不为新模式展示该阈值输入。

## 估计器

新增 `davidson_v2`，保留原批次归一化三结果 Davidson 复合目标、正则化、并列语义、同分网格和分量语义。差异为求解器采用最多 8 组历史向量的 L-BFGS 两层递推，保留全目标 Armijo 检查、正曲率检查、非上升方向回退、取消和非有限值检查。`davidson_v1` 保留原求解路径，Borda 保持基线。

新细排调度使用 v2 / 128 次 / 并列强度 0.1。根据冻结证据的平均有效曝光 e，正则化为 `max(0.001, 0.02 / 4^max(0,e-2))`：初期较强，随证据增加减弱，到五曝光后与最终验证参数 0.001 一致。平均曝光只计算含至少两张可评判图的批次。普通排名与实验面板允许选择三种估计器，并明确配置并列强度；新默认最终拟合为 v2 / 128 / 0.001 / 0.1。真实模型的默认质量仍需真实样本校准。

v2 额外历史内存为 O(N)，报告的工作内存预估增加 192 字节/候选；原版本预估保持不变。该预估不包括图片、网络、数据源及整个进程。没有扩大公开 128 次迭代上限。

算法参考：[L-BFGS 两层递推课程说明](https://pages.cs.wisc.edu/~yudongchen/cs726_sp23/Lecture_23_L-BFGS.pdf)。本实现没有引入外部求解库。

## 验证与限制

先在 5 万图筛选，冻结候选后执行 150 万图理想、随机整批错误、近邻扰动、并列、上下文偏差和混合噪声实验，另设独立真值与采样种子。所有对照统一最终拟合参数和调用预算；成本曲线通过相同批数的证据前缀重放得到，不能解释成各预算下重新规划的反事实结果。

完整方法、负结果、源码哈希、逐批证据与性能观测存于本机 `.local/reports/aesthetic-active-20260924/`，不随 Git 分发。验收摘要见 [验证记录](../verification/2026-09-24-aesthetic-refinement.md)。理想评审中的拓扑排序仅用于诊断证据是否足够及是否被利用，不用于包含矛盾关系的生产排名。
