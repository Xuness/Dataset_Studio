# 0026：美学证据的离线估计、快照与工作集发布

日期：2026-09-18。状态：第二阶段后端实现；前端待接入。

## 职责和证据归属

在第一阶段持久评审之上新增独立的离线执行器。纯计算位于 `studio-application/aesthetic_analysis`，通过 `AestheticReplaySource` 读取有界候选和观测页。这个端口没有 LLM、图片读取、SQLite 或 HTTP 依赖。引擎负责计算准入、取消、项目租约与状态同步；存储负责事务和发布；protocol/client 提供前端契约。

`project.sqlite` 升至 v11，增加离线任务目录和工作集分批构建记录，沿用先备份后迁移。`evaluation.sqlite` 升至独立 v2；迁移 v1 前通过 SQLite Backup API 生成自包含备份，校验后才在事务中增加投影、实验和复核表。未来版本在只读预检阶段拒绝。接受证据表、调用尝试及原始归一化返回不改写。

统计快照存储在独立评审库中，和付费证据分表、分职责，不进入临时缓存回收。当前没有自动删除历史快照的策略，备份包含证据、投影、实验和复核记录；多次百万规模拟合需要相应磁盘空间。完整项目备份仍需整个项目目录。

## 冻结和恢复

离线任务创建时固定阶段配置哈希、候选数、接受证据序号上限和观测数。重放只消费该上限内的接受证据，曝光、不可评判和顶级提名由这些证据重新计算，不读取当前候选表的累计计数作为快照结果。每个快照只使用一个阶段，因此模型、Prompt、图片策略与分组出处保持明确。

实验定义不可变，含 1–12 个估计器变体。创建实验的同一个账本事务固定所有变体的证据水位；重复运行使用相同任务键和相同证据。需要引入新增证据时创建新实验或独立拟合任务，不悄悄修改旧实验。

任务状态为 `queued → running → completed`，失败为 `failed`，取消经过 `cancelling → cancelled`。执行器中断后标记 `interrupted`，由调用方显式 `resume`。拟合和对照的部分输出保持不可见，恢复先分批移除自身未发布的投影，再从冻结证据重算；不会触发远端调用。已完成结果不可改写。

每个运行任务持有项目租约；关闭项目视图不会丢弃后台任务。重启恢复只修正状态，不自动重放付费调用，也不自动启动离线计算。计算执行器与评审图片/HTTP 执行器分别准入：全引擎最多 16 个已准入离线任务，同时计算 1 个，单次上限 100 万冻结候选。纯计算工作内存按 `384 × N + 32 MiB` 做保守规划；这不是整个引擎 RSS 的硬限制。SQL 页、JSON、SQLite 缓存和其它模块还有自身占用。

## 估计器和数值解释

提供两个有版本的实验候选：

- `davidson_v1`：使用胜、负、并列三种结果的 Davidson 图片对模型。每批展开的图片对权重之和为 1，另加零均值二次正则化；对角 Newton 预条件、全目标 Armijo 回溯和每个连通分量的均值归零用于求解。它是整批归一化的复合目标，不是广义 Plackett–Luce 的 listwise 似然，也没有宣称消除批内相关性或模型偏好偏差。
- `borda_v1`：每张图在每批内得到归一化胜/平分，再按有比较信息的批次数平均。它作为消融基线，不校正对手强弱。配置中的正则化和并列强度不参与 Borda 计算。

Davidson 的三结果概率比例为 `u_i : u_j : ν√(u_i u_j)`；实现用对数强度和稳定的 log-sum-exp 计算。模型形式和比较图不可连接时的可辨识性问题可参见 [Yan 的原始研究，§3](https://arxiv.org/html/1411.1168)。支持任意阶并列的 listwise 方法仍可通过同一证据端口加入，见 [PlackettLuce 作者说明](https://hturner.github.io/PlackettLuce/articles/Overview.html)。这些文献不证明本项目已通过真实美学质量校准。

Rating 严格分开。比较图按有效判断构建；并列也建立比较联系，不可评判不当作失败。不同连通分量分别保留分量编号和分量内名次，只有一个 Rating 的全部冻结候选都有比较信息且处于同一分量，才提供 Rating 内名次和百分位。正则化不能用来假装不连通的图片已经建立了比较关系。

`position` 只作为分页位置。`rank_min/max` 是分量内同分范围；`rating_rank_min/max` 只在上述全组可比较条件下存在。数值分数按固定 `1e-6` 网格定义同分，用候选 ordinal 确保展示顺序确定；这些范围不是统计置信区间，也不代表现实审美可精确到这个刻度。百分位从 0（最高）到 1（最低），使用同分组的中间名次。

顶级提名不进入估计器损失、不加分。曝光统计仍以完整批次计数；不同对手数量用 64 位占位草图近似，饱和时估计值为 null、保留已占位数，不伪装为精确对手计数。

## 稳定性、实验对照和复核

可按种子将完整评审批次分到互不重叠的两半，分别拟合。仅当主拟合与两半拟合均收敛、两半都保留原分量的完整连接时，提供两半的分量内百分位差。缺失是信息不足，不能解释成零波动。该指标不是置信区间、独立模型测试或人工认可程度。

`needs_review` 是 v1 检查规则：曝光少于 4、Rating 未完整连通、对手占位少于 8、分半百分位差至少 0.2，或 Davidson 批内平均绝对残差至少 0.4。四次曝光不是稳定性保证；残差也是拟合内诊断。这些规则供筛选和后续校准，不直接替代人工质量结论。

快照对照逐页匹配同一图片身份、内容版本和 Rating。只有对应 Rating 的候选集合完全一致且两侧均完整连通时，发布名次相关、百分位偏移、中段偏移及 Top20 交并比。中段以左侧 20%–80% 为条件；同分用中间名次。没有秩方差时相关系数为 null。其它情况仍提供匹配数量和不具可比性的原因，不把不同候选集的百分位直接相减当作模型冲突。模型分数不跨阶段相加。

复核是追加日志：`protect / confirm_elite / release / defer`，记录图片、快照、操作者和理由。后者是本机调用方填写的出处，不是身份认证签名。保护、确认和待议均留在有效保护池，释放退出池；最新决定覆盖保护选择状态，不修改历史提名和分数。复核目前不把人工意见转换成成对排序训练样本。

## 选择和工作集发布

筛选支持 Rating、年份、明确分量、Top 百分比、名次区间、最大曝光、分半差、复核诊断、仅保护以及与保护池取并集。Top 默认以冻结的 Rating 总体为分母；指定分量时以该分量为分母。并列跨过截断线时保留整个同分组。先限制 Rating/年份，再做保护并集，因此保护候选可越过质量截断、分量、曝光等条件，但不会越过 Rating/年份范围。

预览接口每次最多扫描 4096 行、返回 128 行，可以返回空页及下一游标。游标绑定快照、过滤条件和复核水位。派生请求可携带预览的 `review_watermark`，保证人工查看的池与最终工作集一致；省略时在创建任务时固定最新水位。

新工作集先写普通 `collection_members`，每事务最多 256 个成员；构建记录使其暂时不对工作集列表、管理列表和范围读取可见。每批同时提交已扫描位置与成员数，恢复不会重插已提交成员。扫描完成后用短事务发布 count、谱系和可见状态，不在最后复制百万行。取消或失败保留未发布构建记录供显式续跑。项目库已发布而账本尚未标完成时，续跑先识别已有工作集，再补记完成，不重复生成。已删除工作集保留幂等墓碑，不用旧请求偷偷创建回来。

派生结果是普通固定工作集，下一阶段可选择任何已配置模型和 System Prompt；创建新评审阶段仅冻结，不发起远端调用。当前谱系通过工作集 provenance、父快照和证据水位保存，尚未增加自动多阶段计划编排器。
