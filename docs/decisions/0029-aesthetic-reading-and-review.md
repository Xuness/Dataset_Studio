# 0029：连续看图、保护复核与快照对照

日期：2026-09-23。延续 [0028 公共工作台](0028-frontend-workbench.md)。

排名浏览保持规则图片网格，以 2560×1440、100% 缩放为首要基准。缩略图宽度独立于每页数量，显示设置位于右侧详情。方向键按网格行列移动，左右可跨有界游标页；Enter 进入大图、Esc 返回选中图片。大图支持前后切换、适应窗口、1–4 倍显示缩放和拖动平移。倍率相对于适应窗口，不宣称原图像素级 1:1。

打开大图时保留网格及滚动位置，分页仍为 12/48/96 项，历史游标最多 64 个。媒体继续使用 SDK 的获取、取消与释放机制；大图预览边长请求为 2048。旧浏览草稿没有新增显示字段时补充默认值，不丢弃原快照、Rating、游标或选择。

右侧分为详情、评审依据和保护复核。依据包括快照内名次、可比范围、曝光、分半波动、拟合内分歧及冻结模型和 System Prompt。原始阶段批次通过具名入口定位到相应阶段；它们可能包含快照证据水位之后的批次，不作为这份快照的逐图证据列表。

复核改为侧栏表单，支持保存和保存后下一张。操作者在项目内复用，理由和决定按快照与候选身份保存，最多保留 32 份未完成草稿。提交前将幂等键写入现有草稿存储；响应丢失、关闭视图或刷新后，未修改的内容使用原键重试。记录仍追加，不修改快照分数或历史提名。

排名与保护复核之间切换时沿用当前快照和 Rating；同一范围保留两个视图各自的位置，范围改变时重置目标视图的游标。保护浏览保持进入时的复核水位；保存决定后只刷新单图复核状态，不重排或清空正在处理的队列。用户显式刷新时回到第一页、取得新的保护池。正常排名快照不可变，阅读期间不重复刷新排名页。

公开 `GET /aesthetic/analysis/snapshots/{id}/reviews` 增加可选 `ordinal`：指定时仅返回该图片的记录，按 sequence 降序，`after` 是排他的上界游标；未指定时保留原快照级升序语义。每次至多返回 64 条，存储读取 65 条判断后续页，复用既有 `review_candidate(snapshot_id, ordinal, sequence DESC)` 索引。SDK 增加 `candidateReviews`，不修改数据库格式和写入协议。

实验对照首版通过现有离线 compare 任务比较两份已发布快照。每页 32 条图片明细，任务/快照选择也采用有界分页；结果、选择与游标保存到项目草稿。可比性完全使用后端判断，未知值保持未知。接口的 `percentile_delta` 是绝对偏移，前端仅在可比时用 B 百分位减 A 百分位展示方向，较小表示排名靠前。模型分数不跨阶段相加，提名分歧独立展示。

本轮不改变模型派发协议，也不自动开始付费评审。实验变体的批量配置、真实模型质量校准及目标容量验收仍是后续工作。
