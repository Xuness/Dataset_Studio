# 0018：MetaRecall v2 的元数据阶段

日期：2026-09-13。状态：已采纳。设计依据见《MetaRecall v2.0 实验设计》。首版范围按用户后续要求限定为元数据计算。

## 决定

- 保留 `danbooru.metarecall` 及其原参数、材料格式和公式。新增独立算子 `danbooru.metarecall_v2`，在同一个排名面板中选择。切换方案保留 v2 草稿。
- 共用固定范围、来源快照、断点恢复、校验及发布链路；任务识别同时支持两个算子。未带 v2 配置的旧参数序列化仍不增加该字段。
- v2 输入和评分材料使用版本 2，冻结代表观察的完整标签，并保存原分、百分位、融合分、类型调整、年代偏好和新名次。v1 文件保持原格式，新程序同时读取两版；本次不升级项目数据库结构。
- 按 Rating 单独配置时间上浮、时间下调、负票和年代榜融合权重。初始参数用于试验，不表示已通过视觉验证。
- 年代参考使用跨年 smoothstep 羽化，半宽 0–180 天；0 为硬边界对照。帖龄采用 0–30 天、30–365 天、1–7 年、7 年以上的宽分组。日期精度区间跨组、观察时间未知或有效数量不足时回退已有条件化表现，并保存提示。
- 同一图片可按权重贡献给相邻参考群体，但只占一份排名或候选名额。群体有效数量采用加权有效样本量；两侧都有贡献时，逐图诊断展示较小一侧的有效数量，不把它冒充合并后的独立样本量。
- 年代相对榜只来自元数据，未经过 Bridge Image 视觉校准。首版不抽取视觉锚点、不调用视觉模型、不接入人工图像比较，也不产生图像质量标签或好图概率。
- 两榜在同 Rating 全体合格候选上转换为百分位后融合。保存筛选优先级、年代相对、直算、融合和输入五种查看顺序；v2 固定范围索引增加相应索引，v1 的既有索引身份与读取方式继续可用。
- 类型识别只记录标签线索。漫画单标签、黑白、对白框等不触发降分；2–4 格、多视角、特写、设定展示线索受到保护。扩展漫画线索的软降分可配置，默认 0，防止把未核验线索当成已确认纯漫画。
- 年代软偏好独立于融合分并采用同一羽化权重。目标配额按实际上传年份做整数计数，按每个 Rating 的保留预算分配；严格目标不可行时报错，允许回流时记录回流数量。
- 直榜独有补救、年代榜独有补救和随机审计包含在总预算内。独有入口不足回流主榜；审计在剩余可行年代名额内抽样，不宣称是无配额限制的全库均匀抽样。

## 兼容与验证

新字段由公开协议生成契约，不手改 OpenAPI 或 TypeScript schema。材料校验检查版本、固定输入、分数组成、身份、各榜名次与预算。配置变化产生新成果，不原地重排或覆盖旧文件。

回归覆盖旧方案、加权统计与羽化边界、融合端点、类型保护、硬配额失败及回流、v2 材料往返、五种顺序分页、重启、取消恢复，以及计算期间零图片读取。视觉收益和未看过图片的好图漏失仍需后续独立实验，不能由这些工程检查代替。
