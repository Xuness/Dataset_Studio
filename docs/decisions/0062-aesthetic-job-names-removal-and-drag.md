# 0062：离线任务改名、删除与快照拖放

日期：2026-10-06。延续 [0029 快照对照](0029-aesthetic-reading-and-review.md)。

## 评审账本 v11

`analysis_jobs` 新增 `name` 和 `deleted` 两列，评审账本升级到 v11。与此前一致，从旧版本升级前先在项目内 `.backups` 写入并校验账本备份；旧版引擎无法打开 v11 账本。

- 改名只写 `name`。`request_json` 保持冻结，同一幂等键的重试仍按原请求比对，响应中的 `request.name` 显示新名称。名称规则与其他对象相同：1–120 个可显示字符。
- 删除只把 `deleted` 置 1，不删除行。排队、运行或取消中的任务不能删除。删除后的任务不再出现在任务列表和“阶段最新快照”中，也不能作为新对照、派生工作集或预览的输入；已经生成的对照、工作集、复核记录以及按 ID 读取快照仍可用。
- 删除不释放 `ranking_rows`、`comparison_rows` 占用的空间。两库引用和恢复包校验依赖这些行，真正的回收需要另行设计引用检查。

接口为 `POST /jobs/{id}/metadata`（`{ name }`）和 `POST /jobs/{id}/remove`，SDK 对应 `analysis.rename` 和 `analysis.remove`。

## 前端交互

排名浏览和实验对照的侧栏使用同一种任务行：单击打开，F2 或双击原地改名（Enter 保存，Esc 取消），Delete 确认删除，右键或“更多”按钮打开相同菜单。同一快照可能同时出现在“排名快照”和“离线任务”中，改名状态按所在列表区分。

Windows 上 Tauri WebView 会拦截原生 HTML5 拖放，因此 `@studio/ui` 提供基于指针事件的 `startObjectDrag` 和 `useDropZone`，行为与停靠标签拖动一致：移动 6px 后开始，显示跟随指针的标签，Esc 取消，松开后吞掉起点上的单击。已发布快照可拖到排名画布直接打开，也可拖到实验对照的 A / B 区域；结果表上方拖动时显示左右两半的放置区。快照菜单中的“在实验对照中作为基准 A / 对照 B”切换到实验对照并只替换对应一侧。
