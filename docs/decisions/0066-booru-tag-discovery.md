# 0066：Booru 单标签发现与本地组合筛选

日期：2026-10-07。承接 [0065](0065-empty-lake-initialization.md) 和 [从零建湖计划](../plans/zero-lake-collection-2026-10-07.md)。

## 采集范围

新增 `range.kind=tags`，包含 `query.all / any / none` 与可选 ID 边界。条目必须同时满足全部包含、任选组（非空时至少一个）且不含排除标签。画师和角色使用来源的精确标签；此版本不解释别名、通配符或站点搜索元标签。协议限制标签数量与长度，远端发现必须有正向标签。

有 `all` 时选择一个正向标签作为远端候选来源，其他条件在返回的同一条帖子记录上判断。有 `any` 且没有 `all` 时逐个扫描正向分支，按帖子身份合并任务候选。本地标签统计只用于选择请求成本的估计，不构成远端覆盖依据。矛盾的包含/排除条件直接完成空范围。

使用既有按 ID 升序的有界源站分页，单个请求只加入一个普通 Tag。显式 ID 上界保持固定；未指定时沿用首次获取并冻结本轮源站上界的机制。每页核对 ID、顺序与精确标签，源站忽略条件时保留原始响应并停止，不将错误响应投影成有效数据。

## 元数据和媒体分开

`metadata_ids` 表示本页全部有效元数据，`selected_ids` 表示满足图片条件的条目。全页原文、结构化观察与标签分类依据入湖，未选中条目记为任务范围排除且不下载图片。缺图不影响元数据进度；同一 OR 任务再次遇到已准入的帖子不重置其下载或已完成状态。

全部标签条件由一条观察满足，不以不同日期的 Tag 命中集合拼出一个不存在的联合状态。后续查询可以使用本次取得但没有下载的元数据；跨任务覆盖复用由后续阶段实现。

每个任务保存分支、页数、下一 ID、固定上界与返回/命中记录数。暂停继续保留分支和边界，记录预算计入全部返回候选，空页也是一次扫描。失败、暂停和预算不足不会写成完成。标签范围从不推进 `update_new_metadata_cursor`，归档提交序号仍按原协议连续发布。

## 恢复和版本

归档回执保存两套 ID、查询页边界及任务检查点。响应已保存但尚未封存时，恢复沿用原选择与元数据范围；提交先于控制队列，重复回放幂等。

控制库升级到 12，仅增加执行兼容性隔离：旧运行器可能将未知范围误作普通 ID 扫描，必须先取得旧运行器和执行锁才允许升级。湖归档和在线 schema 保持原值，旧任务、凭据、计划和既有游标不变。已有控制迁移回归使用当前 schema 常量验证最终版本，历史迁移故障点保持原值。

工作台默认提供按标签采集，显示远端候选标签、返回记录、条件命中与已完成分支。返回/命中记录数可能包含 OR 分支的重复观察；任务条目和媒体准入按帖子去重。
