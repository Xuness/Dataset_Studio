# 0064：离线任务的自定义顺序

日期：2026-10-06。延续 [0062 离线任务改名、删除与快照拖放](0062-aesthetic-job-names-removal-and-drag.md)。

## 评审账本 v13

`analysis_jobs` 新增 `sort_key`，评审账本升级到 v13。升级时按原有的 ID 顺序编号，所以已有列表顺序不变；新任务追加到末尾。与此前一致，升级前先在项目内 `.backups` 写入并校验账本备份；旧版引擎无法打开 v13 账本。

- 顺序属于项目数据，不放在应用偏好中。任务列表在服务端分页（每页 32 条），只在前端排序只能调整当前页；顺序存入账本后，“移到最前”对所有分页生效，并随项目迁移和恢复包保留。
- 任务列表按 `(sort_key, id)` 分页。`after` 游标仍是任务 ID，由服务端查出该任务的位置，现有调用方不受影响。
- `POST /jobs/{id}/move` 接受 `{ place: "first" | "last" }`，或 `{ place: "before" | "after", target }`；SDK 为 `analysis.move`。每次移动按新顺序重新连续编号；单个项目的离线任务数量很少，整表重写的代价可以接受。
- 已删除的任务保留原有位置，但不能被移动，也不能作为 `target`。移动与任务状态无关，运行中的任务也可以调整位置。

## 前端交互

排名浏览的“排名快照”和“离线任务”，以及实验对照的“排名快照”和“对照记录”，都可以在列表内拖动排序：

- 指针在目标行上半部分时插入到它之前，在下半部分时插入到它之后，并显示一条插入线；被拖动的行变淡。放在原位置的相邻处不会显示插入线，也不发送请求。
- 只接受同一列表中的行。快照仍可拖到排名画布或实验对照的 A / B 区域。
- 键盘使用 Alt+↑ / Alt+↓ 与相邻行交换位置；菜单提供上移、下移、移到最前和移到最后，其中最前和最后对所有分页生效。
- 移动请求发出后，前端立即按新顺序显示，等列表刷新后再改用服务端顺序。一个移动未完成时，不接受下一个移动。

“排名快照”是“离线任务”中已发布快照的子集，两份列表共用同一个顺序。在任一列表中调整快照的位置，另一份列表也会同步变化。
