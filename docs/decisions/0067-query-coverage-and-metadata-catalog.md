# 0067：查询覆盖复用与独立帖子元数据目录

日期：2026-10-07。承接 [0066](0066-booru-tag-discovery.md)。本阶段保持湖归档 1 / 在线 2 的数据表和物理图片格式，通过控制库与任务回执扩展按需采集。

## 查询覆盖

控制库 schema 13 增加 `discovery_pages` 与 `source_access_epochs`。每个已接受的查询页记录湖、在线代次、访问条件、单标签谓词、实际扫描的左闭右开 ID 区间、原批次/提交、原观察时间和条目数。只记录校验并归档成功的页；错误响应、普通已知帖子集合和未执行的区间不能证明覆盖。

覆盖与控制队列、检查点在同一回放事务提交，依据保存在归档 `query_page` 中。缓存复用回执只引用不可变观察，不重新复制网络响应或写一条伪造新时间的观察。原观察仍可独立从归档恢复；换在线代次时覆盖缓存保守失效。

`refresh={mode:missing_or_stale,max_age_hours:24}` 允许复用新鲜度窗口内的原扫描，条件在原观察上求值；`mode=all` 重新请求源站。旧定义未提供 refresh 时保持原先重新请求的行为与幂等身份。近期记录不是源站即时快照，旧帖新增/移除标签需要重新核验对应查询范围。

有多个必选标签时，先考虑已经有可复用页的标签，再用已有标签统计估计请求成本。每次缓存查询最多检查 64 条邻近覆盖记录，保守漏命中可产生额外请求，不能造成假完成。重叠区间只复用被证明的部分，缺口继续请求；记录预算可在原缓存页中间暂停、接续。原查询完成前已经接受的页也可以贡献覆盖。

未指定上界的任务仅复用真实源站头部请求形成的、仍在新鲜度窗口内的上界。一个人为限定到 ID 100 的任务不会被当成已覆盖全站头部。全站 `update_new_metadata_cursor` 完全独立，限定查询不会推进它。

访问条件使用不含凭据材料的随机 epoch。更新、清除或重新添加凭据均产生新 epoch，防止凭据修订号重置导致旧访问结果误用；正在扫描的范围不跨访问条件混用。原有每湖单执行者避免同湖重复在途扫描，后续任务可复用先前任务接受的页。跨湖分别保留身份和事实。

## 元数据目录和本地选择

`POST /v1/lake-updates/lakes/{id}/posts/query` / SDK `lakeUpdates.catalog` 返回帖子元数据、观察 ID、原获取时间、是否已有图片、稳定版本和分页位置。它查询 `post_versions` 与观察、标签索引，不依赖 `objects` 或已下载图片。

少量正向标签候选使用最多 5000 项的索引定位；大候选或负条件每次最多扫描 2048 个帖子，返回最多 200 条和约 384 KiB 内容。显示标签可以截短，但匹配使用完整索引。空结果页仍可带续读位置，不能误当全查询为空。固定版本受 30 分钟读取租约保护，过期或代次变化明确失败。

`range.kind=tags, source=local` 仅选择已有元数据，允许没有正向标签，支持 `post_ids` 和目录 `version`。任务启动后持有版本租约，复用原观察建立媒体候选；关闭项目不影响任务执行。没有图片的帖子也能被选择，元数据完成与图片补齐各自推进。接口和目录读取受湖位置迁移准入约束。

复用原始 JSON 时逐条检查长度、压缩内容和摘要，限制一批解压量；不一次加载无界原文。HF 等导入观察优先复用已经证明关联的图片，缺少下载输入时只刷新对应帖子。已有 API 地址失效时最多先触发一次元数据刷新，再沿用常规失败/重试行为，避免重复使用同一个失效地址。

相同 MD5 和符合保存策略的图片继续复用；没有 MD5 时仅允许同一不可变观察所关联的已知资产复用。不同观察缺少 MD5 时，仍禁止把新元数据归给未经证明的旧图。

## 时间和验收

远端查询复用读取原扫描事实；目录查询固定一个本地发布版本。两个模式都保留实际观察时间，不能把不同日期的 Tag ID 命中求交后宣称产生了一条联合观察，也不能把任务完成时间显示成源站重新核验时间。

离线验收覆盖 A∩B→A∩C 的零元数据请求复用、B∩C 的缺口补抓、部分扫描、重叠区间、缓存页中间暂停、过期/强制刷新/访问条件变化、不同时间观察、控制回写中断、无图片目录和指定帖子补图。集成验证使用公开 SDK 从目录创建本地采集任务，确认没有新增 API 或图片请求。统计仅证明这些合成场景，不作为真实源站吞吐测量。
