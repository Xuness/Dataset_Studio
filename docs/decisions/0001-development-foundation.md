# 决策 0001：首版底座与开发模式

状态：已采用。

## 选择

- Tauri 2 负责桌面宿主；React / TypeScript / Vite 负责前端。
- 独立 Rust 本机引擎拥有应用和项目状态，通过鉴权回环 API 提供服务。
- 核心通过公开端口与来源、存储实现协作；传输 DTO 与领域对象分开。
- 第一种任务是可验证输入与成果的数据清单，使用独立 Rust 工作进程。
- 首次交付提供 Debug 开发启动脚本。默认脚本只进行增量编译，保留前端热更新和后端重新连接。
- 原数据湖只读，项目成果和本机位置具有不同归属。

## 代价与边界

需要维护宿主、引擎与执行器生命周期，处理文件锁释放与连接恢复。开发引擎使用按构建内容隔离的二进制快照，避免 Windows 可执行文件锁影响后续编译。

首版以一个可运行的纵向功能验证这些边界。算子注册、完整元数据分析和大规模调度将在真实功能需要时扩展。

## 重新评估条件

完整规模测量显示现有分页、存储、预览或任务物化存在瓶颈时，依据数据调整实现；保持稳定的项目身份、来源引用和接口契约。
