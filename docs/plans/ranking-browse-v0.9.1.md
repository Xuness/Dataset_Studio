# 0.9.1 排名工作集浏览

用户已授权接入排名显示、升降序和按 Danbooru ID 定位排名起点。已明确：输入帖子 ID 定位其在当前排名中的位置，再沿排名方向继续浏览；不是按 ID 数值截断成员。

## 行为

- 排名来源的工作集默认使用保存时的榜单顺序；浏览器分别选择排序依据和升降序，展示分级、主排名/补救排名与分数。
- 兼容已有工作集及基于它的查询结果。改变查看顺序或起点不改变固定成员；保存条件中的 top 仍按原依据判定。
- 起点包含定位到的图片；无匹配、未进入当前范围及不兼容游标明确报错。同 ID 多个匹配成员时按当前查看顺序选第一个。
- 排名是分级内排名；反向查看沿完整榜单顺序反向遍历，稳定次序明确。
- 分页和定位都是有界操作。新排名输入附带帖子索引；旧不可变输入采用分段只读定位，提供进度和续接游标，不改写原成果。
- 排序、方向、起点和分页位置随项目保存；改变这些条件使旧分页失效。来源显示名变化不影响浏览身份。
