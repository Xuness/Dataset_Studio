# 0.9 对象管理与选择撤销

用户已授权：项目内数据湖取消关联、工作集与计算结果删除；项目/来源/工作集/成果重命名和备注；具体引用关系与跳转；工作集/成果搜索排序；查询删除和任务历史整理；工作集来源追溯；历史参数复用与命名预设；打开项目/成果目录及复制路径；Ctrl+Z 选择撤销和可配置历史上限。

## 产品行为

- 条目旁的“⋯”提供快捷操作，右侧“属性 / 管理”相邻标签承载详情。排名自己的评分依据面板也能切换管理，避免新增一条永久占宽的栏。
- 数据湖取消关联只作用于当前项目，保留逻辑来源、已固定工作集和成果。停止从该来源读取；重新加入同一数据湖可恢复。正在使用该来源的后台工作需要先结束。
- 删除工作集清理成员和自身引用，保留已固定的任务输入；仍需读取工作集的查询或待准备任务明确列出。
- 成果删除保持受控文件与引用检查，显示具体依赖、文件大小及清理状态。工作集/成果删除后浏览与工具草稿回退到可用对象。
- 查询删除保留旧结果内的定义快照，解除已删除定义自身的引用。任务归档和恢复不改变结果；已结束任务可在没有保留成果时清理输入并移出列表。
- 名称与备注独立于不可变计算材料；项目显示名由项目数据库保存，移动目录和旧结果参数不变。
- 选择撤销记录每次操作的增删差量、选择基底和引用，不按点击复制全量图片身份。Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做；输入框保持原生文本撤销。
- 撤销默认 50 步，可设置 0–200 步；0 关闭历史。项目保存历史以便重开恢复，超限/清空历史时解除对应结果和成果保护。
- 修改历史参数只建立新草稿，不自动启动任务；预设保存参数，不绑定易失效的当前选择。
